## 9. 维护规则（瘦身后的写法约定）

1. **本文件只写"活"的东西**：状态、擂主、结论、铁律速览、导航。**历史一律追加到 `manu/memory/archive/` 或专题档，不往本文件塞**。
2. **写结论必带**：脚本相对路径 + 可复制完整命令 + 执行机 + 产物路径（铁律九）。
3. **改动后必做**：本地 → SSHFS 镜像 → 服务器 **三侧 md5 比对**（铁律〇 / 铁律七）。
4. **Skill 化的判据**：内容是"**怎么做**"（SOP）⇒ 进 `manu/skills/`；是"**做过什么/当前是什么**"（事实）⇒ 进本文件或专题档。
5. **别删归档**：分卷只增不改；引用一律写 §编号 + 导航表。
