### 2.1 已对齐的算子口径（**任务书原文逐项核对过，别改**）

* 核心区 `core_w = max(9, round(w))`、`core_h = max(9, round(h))`；背景环 `ring_size = max(48, 3*max(w,h))`；
  背景环**挖除**核心区**外扩 2 px** 的区域 ⇒ `core & ring == 0`；**平移不裁剪**（保持掩码坐标系）；原生分辨率灰度，**不缩放**。
* `local_scr = P90(|I_core - μ_ring|) / (σ_ring + 1e-5)`（**无极性**，用绝对差 P90）
* `target_local_contrast = P90(|I_core - μ_ring|) / (μ_ring + P90(I_core) + 1e-5)`
* `target_lap_var = Var(cv2.Laplacian(core, CV_64F, ksize=3))`
  ⚠️ **边界口径**：cv2 默认 `BORDER_REFLECT_101`；`ksize=3` 是**对角型**核 `[[2,0,2],[0,-8,0],[2,0,2]]`。
  换零填充 / valid / 十字核 ⇒ `target_lap_var` 差 5~10 倍。**复算器必须同款**。
* 小目标子集：`max(w,h) ≤ 20 px`（任务书 §一.1）。
* 判「跟住」：`CLE_{t+4} ≤ max(5 px, 0.5*max(w,h))`；初始化框 `max(16,w) × max(16,h)`；**5 帧窗口**。
* 膝点双算法：`Kneedle` 与 `PCHIP 最大曲率` 独立提取，偏差 `KNEE_AGREE_PCT = 15.0`（% 量程）⇒ `knee_reliable`；
  曲线先 **Isotonic 单调化 + PCHIP 平滑**。**这一条已实现**（`run_eval_v2.py:83,678-720`）。
* KCF `update()` **滞后一帧** ⇒ 用 **t+5 帧**做尾帧补偿；序列末尾拿不到尾帧的窗口（**205 条 / 8.4%**）必须**显式标注**。

### G2 🔴 仿真底座纯净化（任务书 §二.1）

> 「**严禁把原始画面本身就跟丢的"脏窗口"混入仿真池**（否则会拉低衰减曲线顶部，掩盖真实崩溃拐点）。
> 先在原始无退化视频上运行跟踪器，仅筛选出低误差稳定跟住的『好片段』作为仿真输入底座，保证退化曲线起点纯粹。」

**现状（`run_eval_v2.py:423-479`）**：所有窗口 × 所有退化条件**一次性跑完**，**没有任何好片段筛选**
⇒ 当前 2442 个窗口里有 **15.5% 在干净帧上就已经跟丢**（干净帧跟住率 xcorr 84.5% / kcf 84.6%），这些"脏窗口"正在污染衰减曲线顶部。

**要求**（两趟法）：

1. **Pass A（干净帧分类）**：先跑 `clean` 条件，按**三臂**结果把窗口分成三类（任务书 §三）：
   * **好片段**：5 帧全程稳定跟住，且末帧 `CLE_{t+4} ≤ 3 px`；
   * **一般片段**：未完全跟丢，但 `3 px < CLE_{t+4} ≤ max(5 px, 0.5*max(w,h))`，或**双跟踪器结果分歧**；
   * **跟丢片段**：干净帧下 `CLE_{t+4} > 容限`。
   🔴 「好片段」的定义是**任务书给死的 3 px**，别自己改。
2. **Pass B（退化仿真）**：**只有好片段**进入退化仿真池。
   🔴 底座纯净度要**逐档可查**：退化曲线的起点（clean 档）跟住率应当**≈ 100%**，不是 84.5%。
3. 三臂**各自用自己的分类**（KCF 与 XCorr 的好片段集不一定相同）⇒ 退化池按臂分别取，
   **但三条曲线的对比必须基于「三臂共同的好片段」**才公平（这条自己判断并写清楚理由）。
