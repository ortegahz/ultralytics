对 `contrast` 族（`I' = αI + (1-α)μ`）：

- `local_scr = P90(|I_core − μ_ring|) / (σ_ring + 1e-5)` ⇒ 分子分母**同时乘 α** ⇒ **数学上不变**；
- `target_local_contrast` 分母含 `μ_ring`，同样近似不变；
- 而 XCorr / KCF 都是**归一化**匹配 ⇒ 对整体对比度缩放近乎免疫 ⇒ **跟住率不随 α 塌**。
