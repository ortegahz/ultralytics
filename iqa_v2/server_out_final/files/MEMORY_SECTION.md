### 二、约束线重标（三项核心指标）+ 三分法回归盲测结果

#### 一、曲线有效性守卫（本轮最重要的方法修正）

🔴 **「双算法一致」不能单独证明曲线有效**：在**跟住率从未塌掉**的平曲线上，
Kneedle 与 PCHIP 会一致地落在**同一个噪声箱**上 ⇒ 被误判为可靠。
⇒ 红线候选必须**同时**满足**五道**门禁：
① **分箱曲线跨度 > 5 pp**（= 膝点**实际取自的那条曲线**，下称「指标判别口径」）；
② **逐档跨度 > 5 pp**（= 受控退化轴口径）；③ 跟住率随退化**单调下降**；
④ **指标侧单调下降**（任务书 §四.2）；⑤ Kneedle/PCHIP 双算法偏差 ≤ 15% 量程。

🔴🔴 **本轮审计发现的真缺陷（本轮已修，本节最重要的一条）**：
上一版守卫把**逐档跨度**写进了 `curve_y_span` 列，而**膝点却取自分箱曲线**
⇒ 等于「用 A 曲线的健康度给 B 曲线放行」。实测后果（净化底座上）：
`target_lap_var` / XCorr / `motion` 的**逐档跨度 6.41 pp**（过门槛）但
**分箱跨度仅 1.92 pp**（跟住率在 0.940~0.976 之间抖动）⇒ 上一版发出的
**`target_lap_var < 541.09` 属「双算法 0.00% 一致」的伪一致**，**本轮作废**。
⇒ 本轮把守卫改判在**分箱曲线**上（`curve_y_span`），逐档跨度降为**第二道**守卫
（膝点表新增列 `level_y_span`），并由 `verify_recalc_v2.py` 独立复算双向对账。

**实测分级（`common_good` 池，9 条 臂×族 曲线，以 `local_scr` 为代表曲线）**：
只有 **XCorr 的 `blur`（分箱 19.79 pp / 逐档 7.78 pp）与 `motion`（21.37 / 6.41）** 两条达 A 级；
KCF 的 `blur` 分箱 5.03 pp / 逐档 3.66 pp（逐档不足）⇒ B 级；其余全部 C 级。
⇒ 🔴 **本轮成立的两条线只由 XCorr 一条臂支撑**，**任务书 §二.3 倚重的「XCorr ↔ KCF 算法无关性」
本轮无法复现**（上一轮未纯净化时 `target_lap_var` 两臂偏差 0.00%）。
