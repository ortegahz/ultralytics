## 第 3 页｜标什么：中心点，不是框

**页面内容**

- 标的是**目标中心的一个点**，不是矩形框
- 一个目标 = 一个坐标 `(x, y)`，单位是**原图像素**
- 坐标由工具自动换算，**你只管把点打准**
- 框由算法自己从中心点长出来

**讲稿**

> 最重要的一条先说清楚：我们标的**不是检测框，是目标中心点**。一个目标就是一个坐标，右下角是原图的像素位置。好处是你不用去拉框的四条边，框的松紧度全交给我们算法自己从中心点去长，你只需要保证那个点打在目标身上、特别是打在天上的那个最亮的点或者机身上。
>
> 另外，坐标换算工具已经帮你做完了——画面上可能有黑边、可能窗口被拉伸，你只要在画面上点那个位置，工具自己会算出原图坐标。不要自己去算或者记像素数。

**配图建议**：左图原图、右图标了一个亮绿点的画面，对比说明「框 vs 点」。

## 第 4 页｜每一帧有三种状态

**页面内容**

| 状态 | 含义 | 什么时候用 |
| :-- | :-- | :-- |
| **POS** | 有效正样本：这一帧**有**目标 | 画面里能看到目标 |
| **NEG** | 硬负样本：人工确认过**这一帧没有目标** | 画面干净、确定没目标 |
| **IGN** | 整帧忽略：这一帧**不参与训练** | 画面被遮挡、糊了、没法判 |

- 默认状态是 **IGN**（不标就不会被算进去）
- **NEG 和 IGN 的区别很重要**：NEG 是「我看了，确实没有」；IGN 是「我看不了」

**讲稿**

> 每一帧有三个状态。POS 是有效的正样本，这一帧画面里能看到目标。NEG 是硬负样本，意思是「我人工看过了，这一帧确实没有目标」——这是有价值的负样本，会拿去教模型别乱报。
>
> IGN 是整帧忽略，默认状态就是它。什么情况下用 IGN？画面被遮挡了、严重模糊、根本没法判断有没有目标的时候，标 IGN，这帧就不参与训练了。
>
> 所以 NEG 和 IGN 一定要分清楚：**NEG 是我看清楚了的「没有」，IGN 是「我看不了」**。不确定的时候，宁可标 IGN，不要标 NEG，不然会教模型学错。

## 第 5 页｜双轨数据：你的标注 + 模型的预推

**页面内容**

- **pts** = 人工标注的点（你改的）
- **pred_pts** = 模型预推点（只读，永远不改）
- 两条轨道**分开存**，所以改错了能一键还原
- 画面上能同时看到两种点

**讲稿**

> 这一点特别重要，关系到我们后面能不能复查你的标注。工具里每帧存**两份**点：一份是你人工标的 `pts`，一份是模型预推的 `pred_pts`。模型预推那份是**只读的**，你按什么键都改不动它。
>
> 为什么要这样？因为这样你标错了一帧，可以一键把这一帧退回模型预推的结果，不用重标。如果只有一份数据，标错了就永久污染了。
>
> 在画面上你也能同时看到这两种点：一个是模型的，一个是你的，等下第 9 页会讲怎么认。

## 第 6 页｜怎么打开工具

**页面内容**

- **标注员机器（Windows）**：拿到 `dist\PointAnnotator` 整个文件夹，双击 `PointAnnotator.exe`，**不需要装 Python**
- **源码目录便携启动**：`run.bat D:\视频目录`，**需要同目录 `python\python.exe` 或 PATH 里有 python**（exe 包里不含这个文件）
- **研发 / Linux**：命令行启动（一个参数是视频目录，一个是预推点目录）

```bash
python point_annotator.py /path/to/视频目录 --preannot-dir /path/to/预推点目录
```

- 不带目录参数 → 弹出一个文件夹选择框，手动挑

**讲稿**

> 标注员这边最简单：把 `dist\PointAnnotator` 整个文件夹拷过去，双击 `PointAnnotator.exe` 就行，目标机器不用装 Python。
>
> 注意 run.bat 是**源码目录**里的便携启动脚本，它跑的是 python 程序，必须同目录有 `python\python.exe`、或者系统 PATH 里有 python。exe 包里没有 run.bat，也没有 python，别拿它当标注员的启动方式。
>
> 研发同学在 Linux 上就用命令行，两个参数：第一个是视频目录，第二个是预推点目录。如果第一个参数不写，它会弹一个图形化的文件夹选择框出来，自己挑就行。

## 第 7 页｜第一次打开：选对两个目录（纵横数据实例）

**页面内容**

**第 0 步：把视频拷到能写的地方**（数据集目录是只读挂载，标注存不进去）

```bash
mkdir -p ~/work/标注/videos
cp /home/manu/mnt/data/siping/datasets/manu/纵横AI数据采集_mp4/*.mp4 ~/work/标注/videos/
```

**第 1 步：启动**

```bash
python point_annotator.py ~/work/标注/videos --preannot-dir /home/manu/mnt/data/siping/datasets/manu/纵横AI数据采集_preannot_rc2_tracked
```

- 视频目录：**原始视频** `纵横AI数据采集_mp4`（58 条），但要用**拷出来的副本**做标注
- 预推点目录：`纵横AI数据采集_preannot_rc2_tracked`（**目录名和视频名一一对应**，只读读取没问题）
- 预推点长这样：`VIDEO00033_19700101_003501/000052.txt` + `scores.json`
- ⚠️ **千万别拿 OSD 版视频配预推点**（画面重新排版，点会偏 200~300 像素）

**讲稿**

> 第一次用最容易搞错的就是目录。视频目录要用**原始视频**那个 `纵横AI数据采集_mp4`，预推点用 `纵横AI数据采集_preannot_rc2_tracked`。两个目录里的序列名是**一模一样**的，工具会自动一一对应，你不用改名。
>
> 还有一个必须先做的动作：**先把视频拷到自己能写的地方**。数据集目录是只读挂载，工具的标注文件要写在视频目录下面的 `annotations` 子目录里，直接在数据集目录里标是存不进去的，而**界面不会报错**，你只会以为存上了。所以开工第一步是拷贝，拷完再启动工具。
>
> 重点提醒：旁边还有一个 `纵横AI数据采集_osd_rc2_tracked_th020_20261110`，那是加了画中画和信息面板的版本，画面重新排版过。**拿它配预推点，点会整体偏出去两三百像素**，工具启动时会在日志里告警，但不会自动帮你纠正，因为各个序列的版式还不一样。请大家认准原始视频目录。

## 第 8 页｜界面导览 A：顶部 HUD 一行全解

**页面内容**

```
VIDEO 3/58   FRAME 310/3152   STATE POS   MODE Prev[1]   SNAP OFF   VIEW RAW   MOD:WIN32
```

| 字段 | 含义 |
| :-- | :-- |
| `VIDEO i/n` | 当前第几条视频 / 共几条 |
| `FRAME i/n` | 当前第几帧 / 共几帧（**从 1 开始数**） |
| `STATE` | 当前帧状态 POS / NEG / IGN |
| `MODE` | 推进模式 `Prev[1]` / `Model[2]`（见第 14 页） |
| `SNAP` | 质心吸附 ON / OFF（见第 17 页） |
| `VIEW` | 显示滤镜 RAW / CLAHE / INFERNO |
| `MOD` | 修饰键通道 `WIN32` / `X11` / `NONE` |

- 右上角常驻 **`Switch to ENG IME`**（切英文输入法）
- 红色 **`! NO MODIFIER KEYS`** ⇒ 工具读不到 Shift 状态（大写键在多数后端仍可用，Qt 后端才真退化，见第 20 页）

**讲稿**

> 屏幕最上面这一行是状态栏，实时显示当前在哪。`FRAME` 是帧号，**从 1 开始数**，比播放器习惯的 0 开始多一位，看的时候注意一下。
>
> 右上角那个黄色的 `Switch to ENG IME` 是让你**切到英文输入法**。因为我们所有快捷键都是单个字母，中文输入法开着的话，字母会被输入法吃掉，按了没反应。养成习惯：坐下来第一件事先切英文。
>
> 最后那个 `MOD` 是修饰键通道。正常情况是 `WIN32` 或 `X11`。如果显示 `NONE`，旁边会同时出现红色的 `! NO MODIFIER KEYS`，意思是工具**读不到 Shift 键状态**。这时候大写快捷键大多数情况还能用（工具会退回去按字母大小写判断），但用 Qt 后端的机器上会失效，等下第 20 页细说。

## 第 9 页｜界面导览 B：画面上这三层 + 放大镜

**页面内容**

| 看到的 | 颜色/形状 | 是什么 |
| :-- | :-- | :-- |
| 暗灰十字 | `#A0A0A0` | **上一帧**你确认的位置（残影，看运动趋势） |
| 青蓝空心圆 | `#00C8FF` | **当前帧模型预推点**（只读） |
| 亮绿圆环 + 十字准星 | `#00FF00` | **当前生效的标注**（大而亮的是「激活点」） |

- 右上角 **8 倍放大镜**（248×248），看清像素级位置
- 放大镜焦点优先级：**激活点 → 模型预推点 → 鼠标位置**
- 三个点不重合，就说明模型和你的判断有出入
- **刚打开时绿圈和青蓝圈是重合的**（绿圈画在上层，把青蓝盖住）——因为此刻生效的点**就是**模型点；把点拖偏才看得出两个圈

**讲稿**

> 画面上你同时会看到三种标记。暗灰色的十字是**上一帧**你确认过的点，它是残影，用来帮你判断目标往哪边运动。青蓝色的空心圆是**模型这一帧预推**的点，你动不了它。亮绿色的圆环加十字准星是**你自己当前生效**的标注；一圈大的、中心实心的小亮点，是当前选中的那个「激活点」。
>
> 刚打开视频的时候，绿色和青蓝两个圈是**重合**的，绿色画在上层把青蓝盖住了——因为这时候生效的点用的就是模型的点，不是你标的。**你把点挪开一点点，两个圈就分开了**，这时候才能看出模型和你判断的差别。模型和你判断分开了，就说明模型这一帧跑偏了——这正是我们要你标的价值。
>
> 右上角还有个 8 倍放大镜，能看清像素级别的位置。目标在 1920×1080 的画面里只有几十个像素，不放大很难点准。你鼠标移到哪，它就放大哪；如果你已经点了点，它就优先放大你的激活点。

## 第 10 页｜核心动作①：给这一帧定点

**页面内容**

- **鼠标左键** = 把激活点移到光标处
- 这一帧**一个点都没有** → 左键会**新建**一个点，状态自动变 POS
- 已经有点了 → 左键是**移动激活点**，不是新增
- 想新增第二个目标用 `p`（见第 16 页）

**讲稿**

> 最基本的动作：鼠标左键点一下，点就落到你点的地方。如果这一帧现在一个点都没有，左键会新建一个，而且状态自动变成 POS——你不需要额外去按什么键。
>
> 但要注意：**已经有点了的时候，左键是「移动」而不是「新增」**。所以如果你不小心点到旁边，它会把原来的点拽过去，而不是多出一个点。多目标要用 `p` 键。

**现场演示**：在一个空帧上点一下，点亮绿；再点第二个位置，看它是被移动而不是新增。

## 第 11 页｜核心动作②：微调到像素级

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `w` / `s` | 激活点 **上 / 下** 移 1 像素 |
| `a` / `d` | 激活点 **左 / 右** 移 1 像素 |
| `W` / `S` | **大写**：上 / 下 移 5 像素 |
| `A` / `D` | **大写**：左 / 右 移 5 像素 |

- 自动钳位在图像边界内，**不会跑出画面**
- 没有激活点时按了无效（先左键点一下）
- 大写 = **按住 Shift**，别用 Caps Lock

**讲稿**

> 光靠鼠标点很难精确到像素，这时候用微调键。小写的 `w a s d` 是上下左右各挪一个像素，大写是挪五个像素。
>
> 两个提醒：一是必须先有激活点——你先左键点一下，它才是激活点，大写才有效；二是大写键请**按住 Shift**，别用 Caps Lock。正常情况下 Caps Lock 完全没影响，工具读的是真实的 Shift 状态；但如果这台机器右上角显示 `! NO MODIFIER KEYS`，工具只能退回去按字母大小写判断，这时 Caps Lock 开着会把小写键当成大写，一按就跳 5 像素。所以一律用 Shift。

**配图建议**：截一张放大的画面，箭头标出 1px 和 5px 的差别。

## 第 12 页｜核心动作③：换帧

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `e` / `q` | 下一帧 / 上一帧 |
| `E` / `Q` | **大写**：快进 10 帧 / 后退 10 帧 |
| `Space` | 播放 / 暂停预览 |
| `n` / `i` | 标完后**自动跳下一帧** |

- 按 `e` 推进时，**会按当前推进模式自动带上这一帧的点**（见第 14 页）
- 播到片尾再按 `Space` → **从头重播**

**讲稿**

> 换帧用 `e` 往前、`q` 往后，大写一次跳十帧，用来快速跳过一大段。空格是播放暂停，先用播放整体过一遍再逐帧标，效率高很多。
>
> 有个关键点：按 `e` 推进到下一帧时，工具会**自动把点带到下一帧**——具体带什么，取决于你当前的推进模式，下一页专门讲。
>
> 另外标 NEG 或 IGN 之后会自动跳下一帧，所以连续标的时候不用一直按 `e`。

## 第 13 页｜核心动作④：三种取点来源（重点）

**页面内容**

| 按键 | 来源 | 什么时候用 |
| :-- | :-- | :-- |
| `1` | 采用**上一帧**（t-1）的点 | 目标几乎没动；上一帧刚标过 |
| `2` | 采用**模型预推**点 | **标错了要还原**；模型这帧是对的 |
| `Tab` | 在**上一帧的点**和**模型预推点**之间切 | 两个结果都在眼前，快速比对 |

- `2` 是**无损回退**入口：把人工点退回模型预推，模型预推本身不会被改
- 这三个键都只改 `pts`，**`pred_pts` 永远是只读的**
- ⚠️ **`2` 只在「这一帧有青蓝预推点」时才是还原**。没有预推点的帧按 `2` = **清空当前点**，并把该帧从 POS 变成 IGN
- ⚠️ **`Tab` 不是撤销键**：它切的是「两个来源」，会直接**覆盖你手调过的点**
- ⚠️ **预推点不是逐帧全覆盖**：实测 `VIDEO00033` 3152 帧只有 1068 帧有预推点、`VIDEO00028` 3069 帧只有 441 帧。后半段视频**完全没有青蓝圈**

**讲稿**

> 这是今天最需要记住的一页。每一帧的点，你可以从三个地方来：
>
> 按 `1` 是用上一帧的点。目标基本没动、上一帧你刚标得很好，直接继承过来最省事。
>
> 按 `2` 是用模型预推的点。这个是**还原键**——如果你刚才手滑标错了，按 `2` 一下就退回模型给的结果，你的原始标注不会丢。
>
> 按 `Tab` 是在**上一帧的点**和**模型预推点**这两个来源之间切。模型和你的判断不一致的时候，按一下看看另一个，再按一下切回来，**当场就能比出高下**，不用去查别的地方。要注意它**不是撤销键**——你手调过的点会被它直接覆盖掉。
>
> 记住一条底层规则：**这三个键都只改「生效标注」这一份，模型预推那份是只读的**，所以你怎么折腾都不会把底稿改坏。
>
> 但有两个坑必须讲清楚。第一，**`2` 只在这一帧有青蓝圈的时候才是「还原」**。如果这一帧本来就没有预推点——比如视频后半段——你按 `2` 等于把这个帧的点清空，状态还会从 POS 掉成 IGN。所以按 `2` 之前先看一眼有没有青蓝圈。
>
> 第二，**预推点并不是每一帧都有的**。以 VIDEO00033 为例，一段 3152 帧的视频只有 1068 帧有模型预推点；VIDEO00028 是 3069 帧里只有 441 帧。后半段视频你看到的就是干净的画面，一个青蓝圈都没有，这时候只能靠 `Prev[1]` 继承上一帧，或者自己点。

**现场演示**：在**有青蓝圈**的帧上故意把点拖偏，按 `2` 看它回到青蓝圆的位置；再按 `1` 看它跳到上一帧位置。
（可以顺手演示一下：找一帧**没有**青蓝圈的，按 `2`，点直接消失——让学员记住这个坑。）

## 第 14 页｜核心动作⑤：推进模式 `r`

**页面内容**

| 模式 | HUD 显示 | 按 `e` 推到未编辑的下一帧时 |
| :-- | :-- | :-- |
| **Prev[1]**（默认） | `MODE Prev[1]` | 继承**当前帧**的点 |
| **Model[2]** | `MODE Model[2]` | 采用**该帧的模型预推**点 |

- 按 `r` 切换模式
- 两种模式都**只写生效标注**，不动模型预推
- 自动继承的帧**不算「人工编辑过」**，`edited` 仍是 false

**讲稿**

> 按 `e` 往前走的时候，工具会帮你自动把点带到下一帧，带什么由这个模式决定，默认是 `Prev[1]`。
>
> `Prev[1]` 是**跟上一帧**，适合目标基本不动的情况，比如悬停、或者镜头跟着目标走。
>
> `Model[2]` 是**跟模型**，适合目标在快速移动、逐帧位移明显的情况——这时候跟着上一帧会越来越偏，跟模型每一帧的预测反而更准。
>
> 两种模式都只写生效标注，不会污染模型预推。另外自动继承来的帧不算「人工编辑过」，这个标记只记录你亲自动过的帧——后面讲断点续标的时候会用上。

## 第 15 页｜核心动作⑥：负样本与忽略

**页面内容**

| 按键 | 效果 | 之后 |
| :-- | :-- | :-- |
| `n` | 当前帧 → **NEG**（硬负样本） | **自动跳下一帧** |
| `i` | 当前帧 → **IGN**（整帧忽略） | **自动跳下一帧** |

- 这两个键会**清空该帧生效的点**（模型预推点仍保留在 `pred_pts` 里）
- 已经有 NEG/IGN 的帧，不会因为「画面上有个预推点」被自动升成 POS
- 用 `n` 之前先确认画面里**真的没有目标**
- ⚠️ 已标 NEG 的帧，再按 `1`/`2`/左键，**会被翻成 POS**（有点就自动变正样本）
- ⚠️ `Model[2]` 模式下按 `n`/`i` 之后，**下一帧会被自动置成 POS**（继承了那帧的模型点）

**讲稿**

> `n` 标硬负，`i` 标忽略，两个都会自动跳到下一帧，所以可以一路按着往下走。
>
> 注意它们会把这一帧生效的点清掉，但模型预推点还留在记录里，随时能按 `2` 找回来。
>
> 用 `n` 之前一定要看清：模型在这一帧可能误报了一个点。如果你直接按 `n`，实际上是在说「这帧没目标」，而模型说有——那说明模型误报了，这正是我们想要的负样本，是有价值的。但如果目标其实在画面里只是很小很暗，你按 `n` 就是**教模型学错了**。所以：**看清楚了再按 `n`，看不清楚按 `i`。**
>
> 还有两个连带效应要注意。一是**已经标了 NEG 的帧，你再按 `1`、`2` 或者左键点一下，只要那一帧有了点，状态就自动变成 POS**——因为工具的规则是「有点就是正样本」。所以标完 NEG 别再在这一帧上乱按。
>
> 二是**在 `Model[2]` 模式下按 `n` 或 `i` 之后，你可能会看到下一帧凭空多出一个绿圈**——那是工具把下一帧的模型预推点自动带过来了，不是它替你判了这一帧有目标。看到绿圈不要当成「已经标好了」，该确认还是确认。

## 第 16 页｜核心动作⑦：多目标场景

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `p` | 在**鼠标位置**新增一个点（新点自动成为激活点） |
| `c` | 删除当前激活点 |
| 鼠标左键 | 移动激活点 |

- 多个目标时，**大而亮的那个是激活点**（`w a s d` / `p` / `c` 都作用于它）
- 删点后激活点自动落到相邻的点上
- ⚠️ **把最后一个点删光，这一帧会从 POS 变成 IGN（不是 NEG）**——清空点不等于「确认过这里没目标」

**讲稿**

> 画面里有多个目标的时候，按 `p` 在鼠标位置新增一个点。新增出来的点自动变成激活点——那个大而亮的绿色圆环。微调、删除都只对激活点生效，所以要改哪个，就先点它或者刚 `p` 出来让它成为激活点。
>
> 按 `c` 删除激活点。删掉之后，如果还有别的点，激活点会自动落到相邻的一个上，不用重新点。
>
> 补一句容易忽略的：**把最后一个点删光，这一帧的状态会回到 IGN，不是 NEG**。因为「没有点」只代表没标，不代表人工确认过这一帧没目标。要标成硬负，得按 `n`。

**现场演示**：`p` 加两个点，用 `w a s d` 分别移动，观察大亮点跟着换。

## 第 17 页｜显示辅助：吸附 / 滤镜 / 放大镜

**页面内容**

| 按键 | 功能 | 说明 |
| :-- | :-- | :-- |
| `t` | **质心吸附** ON / OFF | 在 7×7 邻域内算「局部背景减除后的亮度质心」，点上去自动吸过去 |
| `Alt` + 左键 | 临时禁用吸附 | **不改变** `t` 的开关状态 |
| `v` | 切换显示滤镜 | RAW → CLAHE → INFERNO 循环 |
| `h` | 开关快捷键浮层 | 忘了按键就按它 |

- 吸附**默认关闭**：避免大目标点击机身中心时被吸偏到单个电机高热点
- 滤镜**只影响显示**，不改原始像素、不改标注数据

**讲稿**

> 三个辅助功能。`t` 是质心吸附，开启后你点一下，工具会在附近 7×7 的范围里算目标的亮度重心，把点自动吸过去。但它**默认是关的**，这是有意的：目标比较大的时候，你点的是机身中心，吸附可能会把你吸到某个电机的高光点上，反而更错。
>
> 如果你确实想用吸附，又担心吸歪，可以按住 `Alt` 再点，临时关掉吸附这一次，`t` 的开关状态不变。
>
> `v` 是显示滤镜，RAW 是原图，CLAHE 是增强对比度，INFERNO 是伪彩。暗目标看不清的时候切 CLAHE 很有用。滤镜**只改显示**，不碰原始数据，你存出来的坐标永远是在原图上的。

## 第 18 页｜切视频 & 断点续标

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `[` | 上一条视频 |
| `]` | 下一条视频 |

- 重新打开同一目录 → **自动续标**，停在**第一帧还没被人动过**的位置
- ⚠️ 「动过」= 你**亲手点过 / 调过 / 标过状态**的帧；靠 `e` 自动继承或 `E` 跳过的帧**不算** ⇒ 续标可能退回很靠前的位置
- 全部帧都标过了 → 停在末帧
- 加载优先级：`annotations/<视频名>.json`（你的产出）→ 视频目录下的同名 `.json` → `--preannot-dir` 预推点

**讲稿**

> `[` 和 `]` 在目录里的视频之间跳，跳过去会自动把当前视频存一遍。
>
> 中途被打断了、或者换台机器接着标，直接重新打开同一个视频目录就行——工具会找到你之前存的 `annotations` 文件，**自动停在第一帧还没被人动过的地方**，接着往下标就行。全部都标完了，它就停在末帧。
>
> 但这个「动过」的定义要讲清楚：它指的是**你亲手点过、调过、或者标过状态的帧**。如果这一段你是按 `e` 一路继承下来、或者按 `E` 跳着看的，那些帧**都不算动过**，重新打开就会退回到那一段的起点。**这不是坏了**——工具不记「上次看到第几帧」，它只认「哪一帧被人动过」。所以收工前最好把今天真正逐帧看过的地方都点过一遍。
>
> 加载的时候有优先级：你自己的产出优先，其次是视频目录下的同名 json，最后才是预推点目录。所以别怕和预推点打架。

## 第 19 页｜保存与产出

**页面内容**

- 落盘位置：`<视频目录>/annotations/<视频同名>.json`
- **一次改动一次落盘**，原子写（临时文件 + 替换），**崩了不会留半截文件**
- 退出键：`ESC`（或 `x`）→ **自动保存并退出**

```json
{
  "video": "VIDEO00033_19700101_003501.mp4",
  "resolution": [1920, 1080],
  "frames": {
    "310": { "state": "pos", "pts": [[845, 418]], "pred_pts": [[847, 420]], "edited": true },
    "311": { "state": "neg", "pts": [],       "pred_pts": [[1120, 380]], "edited": true }
  }
}
```

- `state` 状态 · `pts` 人工点 · `pred_pts` 模型点 · `edited` 是否人工动过

**讲稿**

> 你标的东西存在**视频目录下的 `annotations` 子目录**里，一个视频一个 json，文件名和视频同名。原始视频目录本身不会被弄脏。
>
> 每次改动都会立刻存盘，而且是原子写——先写临时文件再替换，所以断电、程序崩了都不会留个半截文件把你之前的标注搞丢。
>
> 退出按 `ESC` 就行，会自动保存。如果你的机器上 ESC 被系统吃掉了，还有一个 `x` 键一样的作用。

## 第 20 页｜五个常见的坑

**页面内容**

| # | 坑 | 后果 | 怎么办 |
| :-- | :-- | :-- | :-- |
| 1 | **中文输入法没切英文** | 单字母键全被吞掉，按了没反应 | 看右上角 `Switch to ENG IME` |
| 2 | **拿 OSD 版视频配预推点** | 点整体偏 200~300 px | 用原始视频 `纵横AI数据采集_mp4` |
| 3 | **HUD 显示 `! NO MODIFIER KEYS`** | 读不到 Shift 状态；多数后端靠字母大小写兜底，Qt 后端 `W/A/S/D` 会退化成 1px、`E/Q` 退化成 ±1 帧 | 一律用 Shift 触发大写；必要时换机器 |
| 4 | **视频目录只读** | 存盘失败，**界面不报警**（只在 `point_annotator.log` 留一行） | **先拷到可写目录再标**；开工后确认 `annotations/` 里真的生成了 json |
| 5 | **不清空点就标 NEG** | 把有目标的帧教成负样本 | 看不清按 `i`（IGN），别按 `n` |

**讲稿**

> 五个坑，前两个最常见。
>
> 一，中文输入法。单个字母会被输入法吃掉，你按 `e` 什么都没发生。先切英文，这是第一件事。
>
> 二，用错视频目录。OSD 版视频画面重新排版过，配预推点点会整体偏出去两三百像素。记住用原始视频那个目录。
>
> 三，如果 HUD 出现红色的 `! NO MODIFIER KEYS`，说明这台机器读不到 Shift 状态。多数后端还能靠字母大小写兜底，小写键完全正常；但如果这台机器走的是 Qt 后端，大写键会全部退化成小写效果——五像素变成一像素，十帧变成一帧，只是慢一点，不影响干活。**统一用 Shift 触发大写**。
>
> 四，标注目录要是只读的，你存不进去，而且**界面不会报错**，只会在 `point_annotator.log` 里留一行——你会以为存上了。所以开工前先把视频拷到自己能写的目录，标完第一段就去看一眼 `annotations/` 目录里有没有生成 json 文件，确认真的存上了。
>
> 五，最容易造成**数据污染**的一条：画面里其实有目标，但你按了 `n` 标成负样本——这等于教模型「这里没有目标」，直接损伤模型。看不清就按 `i` 标忽略，宁可少标也不要标错。

## 附：讲这份课件时的补充说明（不用做成 PPT 页）

- **演示素材准备**：提前把 `纵横AI数据采集_mp4` 里挑 2~3 条视频拷到可写的演示目录，并跑一遍命令确认预推点能正常加载。
- **回放检查点**：如果培训时间紧张，第 13 页（三种取点来源）和第 20 页（五个坑）是**不可删**的；第 17 页（显示辅助）可以简略带过。
- **答疑高频点预判**：
 1. 「大写键没反应」→ Shift 键位 / Caps Lock / `MOD:NONE` 三种可能，按第 20 页第 3 条排查；
 2. 「点打不准」→ 放大镜 + 1px 微调，必要时开 `t` 吸附（或 `Alt` 临时禁用）；
 3. 「标错了怎么办」→ 按 `2`（**先确认这一帧有青蓝圈**，没预推点时按 `2` 会清空当前点并把状态打成 IGN）；
 4. 「文件存哪了」→ `<视频目录>/annotations/<视频同名>.json`，ESC 退出即自动保存；
 5. 「怎么确认真的存上了」→ 看 `annotations/` 里有没有生成 json；存盘失败只在 `point_annotator.log` 留一行，界面不报警；
 6. 「重开为什么回到很前面」→ 续标只认「被人动过」的帧，`e` 继承 / `E` 跳过的帧不算动过（见第 18 页）；
 7. 「后半段视频一个青蓝圈都没有」→ 预推点本来就不是逐帧全覆盖，后半段只能靠 `Prev[1]` 或自己点。
- **培训现场必须先验证的一件事**：演示机上先跑一遍 `h` 帮助浮层 + 标一帧 + 确认 `annotations/` 里真的生成了 json，再开始讲第 19 页（否则「存盘是静默的」这条坑无法当场演示）。
- **不要在课件里承诺的事**：工具目前**不会**自动做坐标变换，OSD 版视频与预推点的坐标系不兼容只能靠人注意；也不支持多边形、旋转框，只标中心点。
