## 第 2 页｜界面速览

**页面内容**

**顶部 HUD**

```
VIDEO 3/58   FRAME 310/3152   STATE POS   MODE Prev[1]   SNAP OFF   VIEW RAW   MOD:WIN32
```

`VIDEO i/n` 第几条视频 · `FRAME i/n` **第几帧（从 1 数）** · `STATE` 当前帧状态 · `MODE` 推进模式 ·
`SNAP` 吸附开关 · `VIEW` 显示滤镜 · `MOD` 修饰键通道

**画面上的三种标记**

| 看到 | 是什么 |
| :-- | :-- |
| 暗灰十字 | **上一帧**的点（看运动趋势） |
| 青蓝空心圆 | **模型预推**的点（只读，改不动） |
| 亮绿圆环 + 十字准星 | **当前生效**的标注（大而亮的是**激活点**） |

- 右上角 **8 倍放大镜**（焦点：激活点 → 模型预推点 → 鼠标位置）

**⚠️ 注意**

- 右上角常驻 `Switch to ENG IME` ⇒ **先切英文输入法**，否则单字母键被输入法吃掉
- 红色 `! NO MODIFIER KEYS` ⇒ 读不到 Shift，多数机器仍能用大写键，但统一用 Shift 触发
- 刚打开时绿圈和青蓝圈**重合**是正常的（生效点此时就是模型点），把点拖偏才看得出两个圈

**现场演示**：打开一条视频，指出 HUD 各字段；把鼠标移到目标上，展示放大镜。

## 第 3 页｜定点与微调

**页面内容**

| 操作 | 作用 |
| :-- | :-- |
| **鼠标左键** | 把**激活点**移到光标处（该帧没点时 = 新建一个，状态自动变 POS） |
| `w` / `s` | 激活点 上 / 下 移 **1 px** |
| `a` / `d` | 激活点 左 / 右 移 **1 px** |
| `W` / `S` | 上 / 下 移 **5 px** |
| `A` / `D` | 左 / 右 移 **5 px** |

- 微调只作用于**激活点**，且自动钳位在画面内

**⚠️ 注意**

- 已经有点了，左键是**移动**不是新增 ⇒ 多目标要用 `p`（第 8 页）
- 大写要**按住 Shift**，别用 Caps Lock
- 没有激活点时微调键无效，先左键点一下

**现场演示**：点一下目标 → 用 `w a s d` 挪 1 px → 用 `W` 跳 5 px。

## 第 4 页｜换帧与播放

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `e` / `q` | 下一帧 / 上一帧 |
| `E` / `Q` | 快进 10 帧 / 后退 10 帧 |
| `Space` | 播放 / 暂停预览 |

- 按 `e` 推进到**还没人工编辑过**的帧时，会**自动带上点**（带什么取决于推进模式，第 6 页）
- 播到片尾再按 `Space` ⇒ **从头重播**

**⚠️ 注意**

- `e` 带过去的点来自上一帧或模型，**不一定准** ⇒ 每一帧都要看
- 标完 `n` / `i` 会**自动跳下一帧**，连续标时不用一直按 `e`

**现场演示**：空格播一段 → `e` 逐帧停 → `E` 跳 10 帧。

## 第 5 页｜三种取点来源（重点）

**页面内容**

| 按键 | 来源 | 什么时候用 |
| :-- | :-- | :-- |
| `1` | **上一帧**（t-1）的点 | 目标几乎没动；上一帧刚标过 |
| `2` | **模型预推**点 | 标错了要还原；模型这帧是对的 |
| `Tab` | 在**上一帧的点**和**模型预推点**之间切 | 两个结果都在眼前，快速比对 |

- 模型预推那份**永远不会被改**，所以误操作随时能退回去

**⚠️ 注意**

- **`2` 只在「这一帧有青蓝圈」时才是还原**：没有预推点的帧按 `2` = 清空当前点，并把状态打成 IGN
- **`Tab` 不是撤销键**：它切的是两个**来源**，会直接覆盖你手调过的点
- **预推点不是每帧都有**：实测 `VIDEO00033` 3152 帧只有 1068 帧有、`VIDEO00028` 3069 帧只有 441 帧
  ⇒ 后半段视频一个青蓝圈都没有，只能靠 `Prev[1]` 继承或自己点

**现场演示**：把点拖偏 → `2` 回到青蓝圈 → `1` 跳到上一帧位置 → 再找一个没青蓝圈的帧按 `2`（点消失），记住这个坑。

## 第 6 页｜推进模式 `r`

**页面内容**

| 模式 | HUD 显示 | 按 `e` 推到未编辑的下一帧时 |
| :-- | :-- | :-- |
| **Prev[1]**（默认） | `MODE Prev[1]` | 继承**当前帧**的点 |
| **Model[2]** | `MODE Model[2]` | 采用**该帧的模型预推**点 |

- 按 `r` 切换
- 两种模式都只写生效标注，**不动模型预推**

**⚠️ 注意**

- 目标**基本不动 / 悬停 / 镜头跟着走** ⇒ 用 `Prev[1]`
- 目标**移动快、逐帧位移明显** ⇒ 用 `Model[2]`，跟着上一帧会越来越偏
- 自动继承来的帧**不算「人工编辑过」** ⇒ 断点续标会退回去（见第 11 页）

**现场演示**：`r` 切两次，看 HUD 的 `MODE` 变化；用 `e` 走三帧看点是否被带过去。

## 第 7 页｜帧状态 `n` / `i`

**页面内容**

| 按键 | 效果 | 之后 |
| :-- | :-- | :-- |
| `n` | 当前帧 → **NEG**（硬负样本：确认过这帧没目标） | **自动跳下一帧** |
| `i` | 当前帧 → **IGN**（整帧忽略，不参与训练） | **自动跳下一帧** |

- 这两个键会清空该帧生效的点（模型预推点仍保留）

**⚠️ 注意**

- **NEG = 看清楚了的「没有」，IGN = 「看不了」** ⇒ 看不清一律按 `i`
- 已经有 NEG/IGN 的帧，不会因为画面上有个青蓝圈被自动升成 POS
- **已标 NEG 的帧再按 `1`/`2`/左键 ⇒ 会被翻成 POS**（有点就是正样本）
- **`Model[2]` 模式按 `n`/`i` 后，下一帧会被自动置成 POS**（它把模型点带过来了，不是替你判了）

**现场演示**：找 2 帧没目标的按 `n`、2 帧看不清的按 `i`；再在 NEG 帧上按 `1`，看状态变回 POS。

## 第 8 页｜多目标 `p` / `c`

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `p` | 在**鼠标位置**新增一个点（自动成为激活点） |
| `c` | 删除当前**激活点** |
| 鼠标左键 | 移动激活点 |

- 多个目标时，**大而亮的那个是激活点**；`w a s d` / `p` / `c` 都只作用于它
- 删点后激活点自动落到相邻的点上

**⚠️ 注意**

- **把最后一个点删光，这一帧会从 POS 变回 IGN（不是 NEG）** ⇒ 要标硬负必须按 `n`

**现场演示**：`p` 加两个点 → `w a s d` 分别移动 → `c` 删掉一个。

## 第 9 页｜显示辅助

**页面内容**

| 按键 | 功能 |
| :-- | :-- |
| `t` | **质心吸附** ON / OFF（7×7 邻域算亮度质心，点上去自动吸过去） |
| `Alt` + 左键 | **临时**禁用吸附（不改变 `t` 的开关状态） |
| `v` | 显示滤镜循环：RAW → CLAHE → INFERNO |
| `h` | 开关快捷键浮层（忘了键位就按它） |

- 滤镜**只影响显示**，不改原始像素、不改标注数据

**⚠️ 注意**

- 吸附**默认关闭**是有意的：大目标点机身中心时可能被吸偏到某个电机高热点
- 暗目标看不清 ⇒ 切 `v` 到 CLAHE

**现场演示**：`h` 打开帮助浮层；`v` 切到 CLAHE 看暗目标；`t` 开吸附点一下再 `Alt`+点对比。

## 第 10 页｜切视频

**页面内容**

| 按键 | 作用 |
| :-- | :-- |
| `[` | 上一条视频 |
| `]` | 下一条视频 |

- 切过去时当前视频会自动存盘
- 目录里的视频按文件名排序

**⚠️ 注意**

- 换视频前确认当前这条已经标完并存上了（看 `annotations/` 目录）

**现场演示**：`]` 跳下一条，看 HUD 的 `VIDEO i/n` 变化。

## 第 11 页｜保存与产出

**页面内容**

- 退出键：**`ESC`**（或 `x`）⇒ **自动保存并退出**
- 落盘位置：`<视频目录>/annotations/<视频同名>.json`
- **一次改动一次落盘**，原子写 ⇒ 崩了不会留半截文件

**⚠️ 注意**

- **视频目录必须可写**：只读目录会存不进去，而且**界面不报警**，只在 `point_annotator.log` 留一行
  ⇒ 开工第一步确认 `annotations/` 里真的生成了 json
- **断点续标只认「被人动过」的帧**：`e` 继承 / `E` 跳过的帧不算 ⇒ 重开会退回很靠前，不是上次位置

**现场演示**：标一帧 → 退出 → 到 `annotations/` 目录确认 json 生成了 → 再打开看是否续标。

## 第 13 页｜五个坑

**页面内容**

| # | 坑 | 后果 | 怎么办 |
| :-- | :-- | :-- | :-- |
| 1 | **中文输入法没切英文** | 单字母键全被吞掉 | 看右上角 `Switch to ENG IME` |
| 2 | **在没青蓝圈的帧按 `2`** | 当前点被清空、状态变 IGN | 按 `2` 前先看有没有青蓝圈 |
| 3 | **视频目录只读** | 存不进去，**界面不报警** | 先拷到可写目录；确认 `annotations/` 真生成了 json |
| 4 | **画面里明明有目标却按 `n`** | 把有目标的帧教成负样本，污染数据 | 看不清按 `i`，别按 `n` |
| 5 | **在 NEG 帧上又按 `1`/`2`/左键** | 状态被翻成 POS | NEG 标完别再动这一帧 |

## 第 14 页｜实操练习（10 分钟）

**页面内容**

1. 打开工具，选好视频目录，**切英文输入法**
2. 一段视频连续标 20 帧：每帧 `e` 前进 → 左键定点 → `w a s d` 微调
3. 故意标错一帧，按 `2` 还原；再找一帧没青蓝圈的按 `2`，看它清空
4. 找 5 帧确实没目标的按 `n`，找 2 帧看不清的按 `i`
5. `p` 加一个多目标，`c` 删掉
6. `r` 切一次推进模式，`v` 切一次滤镜，`t` 开一次吸附
7. `[` `]` 切视频，确认每条都存盘
8. 退出再打开，确认**续标**停在「第一帧没被人动过」的位置

**现场演示**：全程巡场，重点盯第 3、4 条（这两个错了会污染数据）。
