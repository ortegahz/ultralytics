## 一、系统核心算法架构 (Two-Pass Architecture)

### Pass 1：在线自适应两阶段打捞关联 (Online Kinematic Pass)
1. **分级闭环打捞（Two-Tier Salvaging）**：
   - **高确信点（Score >= th_base = 0.22）**：负责发起新航迹并更新现有航迹；
   - **弱脉冲打捞池（0.06 <= Score < 0.22）**：**严禁自发生成新航迹**，只允许被现有存活航迹在运动学门限（`match_dist=12.0px`）内进行打捞，从数学上杜绝传感器随机白噪声串接为假警航迹；
2. **空域悬停豁免机制（Sky Hovering Exemption）**：
   - 在平坦纯净的空域部分（$y < 0.6 \times H$），豁免静止微位移截断（`min_displacement=2.5px` 仅在地表杂波区生效），彻底保全空中悬停静止无人机；
3. **空气动力学动态机动拓展门限（Dynamic Maneuver Gating）**：
   - 依据无人机航迹速度模长实时放大关联窗口至 $12.0 \sim 18.0\text{px}$，消除急转弯脱靶。

### Pass 2：离线双向时空平滑、缝合与插补 (Bidirectional Smoother)
1. **时序碎片航迹缝合（Kinematic Tracklet Stitching）**：
   - 提取各航迹碎片终点的运动学状态（末端速度矢量 $\vec{v}$ 与位置），在时间断裂带（$1 \le \Delta t \le \text{stitch\_gap}=4$ 帧）内进行动力学外推。若空间距离满足动力学容差（$\text{dist} \le \max(25.0, 10.0 \times \Delta t)$），自动缝合为单条长航迹；
2. **高确信航迹受控插补（Confirmed Track Infill / RTS-like Interpolation）**：
   - **安全权限**：仅对存活累计命中 $\ge 5$ 帧的高置信度真实长航迹（`min_hits_infill=5`）开放插补；未确信的偶发杂波严禁插补；
   - 在内部出现的短暂失锁间隙（$\le 3$ 帧），进行平滑双向动力学线性插补；
3. **冷启动前缀无损回填（Prefix Recovery）**：
   - 航迹确认后，自动追溯回填前 1、2 帧的初始观测点，消除传统 $M/N$ 关联的冷启动漏检。
