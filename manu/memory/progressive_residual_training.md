# 渐进式组件扩容与受控残差微调方法论 (Progressive Residual Component Scaling & Staged Fine-Tuning)

> **定位与使命**：沉淀红外弱小目标模型从“参数翻倍反倒退”到“超轻量增量组件突破”的核心工程范式。详尽记录如何通过“**物理冻结底模 + 全分辨率侧支 + 零初始化恒等门控**”实现零回归、高保真性能跃迁，作为后续所有单帧架构演进与 SOTA 复现的黄金标准。

---

## 一、核心问题背景：为什么常规全参微调与粗暴扩容必死？

在红外弱小目标（1~3px 脉冲）小样本体制下，探索模型演进曾面临两大致命陷阱：
1. **陷阱一：粗暴全网加宽（YOLO26s 失败复盘）**
   - 将通道数全局翻倍（7.13M 参数），参数大量堆叠在无用的深层（P4/P5、SPPF、注意力）；
   - 在 100,000:1 极端负样本背景下，大模型强大自由度走捷径“过度拟合背景并将输出压向负无穷”，导致工作门限被死死锁在 0.45~0.50，弱小目标因门限截断大面积漏检（Recall 卡死在 75.33%）。
2. **陷阱二：收敛模型全参数微调（Gaussian Relaxation 实测复盘）**
   - SOTA 模型（如 Trial 22）是在高维损失曲面中经 100+ 轮 Optuna 找到的极脆弱平衡点；
   - 只要主干参数全部解冻参与反向传播，AdamW 动量瞬间冲垮已有空间响应先验；
   - 出现“**训练集 Loss 单调下降，验证集 TP 大幅暴跌（首轮净丢 282 目标）**”的严重衰退。

## 二、渐进式组件微调四步黄金法则 (The 4-Pillar Residual Paradigm)

为彻底解决上述两难困境，确立“渐进式组件扩容”核心工程规范：

```text
               输入原图 X: [I_t, Diff, Median] (640x640)
                           │
       ┌───────────────────┴───────────────────┐
       ▼                                       ▼
【第一阶段：物理绝对冻结底模】           【第二阶段：极轻量全分辨率侧支】
- 加载已收敛 SOTA 权重 (Trial 22)       - 保持 640x640 全分辨率无损
- 1,790,531 参数 requires_grad=False   - 仅 Conv(3->16) + DWConv(16->16)
- BatchNorm 锁定为 eval() 模式          - 仅 1,793 个专属参数
- 零风险锁定现有 95.51% 精确率          - 专门捕获下采样丢失的 1~2px 脉冲
       │                                       │
       │                                       ▼
       │                              【第三阶段：峰值保持与投影】
       │                              - MaxPool(2x2) 下采样 (无模糊)
       │                              - Proj(16->48) 维度对齐
       │                                       │
       │                                       ▼
       │                              【第四阶段：零初始化恒等门控】
       │                              - 标量 gate alpha 严格初始化为 0.0
       │                              - 训练第 0 步严格等价于 SOTA 底模
       │                                       │
       └───────────────────┬───────────────────┘
                           ▼
                  F_final = F_base + alpha * ΔF_p0
                           │
                           ▼
                 [输出端 Heatmap Head] (保持冻结)
```

### 1. 支柱一：底模参数 100% 物理绝对冻结 (Strict Base Isolation)
- **代码实现**：
  ```python
  for name, param in model.named_parameters():
      if "p0_highway" in name:
          param.requires_grad = True
      else:
          param.requires_grad = False
  ```
- **运行态保护**：训练循环中必须强制将冻结模块置于 `eval()` 状态，防止 BatchNorm 统计量（running_mean/running_var）被微调 batch 污染：
  ```python
  for name, m in model.named_modules():
      if "p0_highway" not in name:
          m.eval()
  ```
- **核心收益**：底模建立的超强复杂地物与晃动杂波判决面被物理锁死，杜绝灾难性遗忘。

### 2. 支柱二：全分辨率浅层保真设计 (Full-Resolution P0 Highway)
- **物理机理**：主干网络的首层下采样（Stride=2 / 320x320）会使焦平面仅占 $1\sim 2\text{px}$ 的极弱小冲激与周围 3 个暗像素进行加权平均，信噪比骤降 75% 且发生高频能量发散；
- **侧支拓扑**：在 $640\times 640$ 原始分辨率上仅做 $3\times 3$ 卷积与深度可分离卷积，参数量仅 **1,793 个（约 0.002M）**；
- **汇聚方式**：下采样至 320x320 时强制使用 **MaxPool2d(2, 2)**，直接抓取局部 $2\times 2$ 窗口内的最大冲激极大值，绝不引入双线性或步长加权平均模糊。

### 3. 支柱三：零初始化恒等门控机制 (Zero-Initialized Residual Gate)
- **数学表达式**：
  $$F_{\text{final}} = F_{\text{p1\_base}} + \alpha \cdot \Delta F_{\text{p0}}$$
- **初始化原则**：
  $$\alpha \leftarrow 0.0$$
- **核心工程定性（Zero Regression Guarantee）**：
  在微调的 Epoch 0 Step 0，由于 $\alpha=0.0$，模型输出在数学浮点精度上与 SOTA 底模 **100% 恒等**。后续反向传播仅在侧支特征能够产生确定性正向收益时才驱动 $\alpha$ 演进，彻底杜绝新组件接入带来的早期断崖式性能崩溃。

### 4. 支柱四：梯度目标极致解耦 (Gradient Objective Decoupling)
- 优化器不再需要在“压制 10 万个背景负样本”与“学习弱目标”之间两难平衡；
- 1,793 个新增参数只专注于一个纯粹目标：**学习空间高频残差补偿量**。收敛速度极快（仅需 5~8 轮短微调即可验证），且显存开销几乎为零。

## 四、第二代升级：运动引导空间 SCR 门控纯冷启动实测 (P0 v2: Spatial-Guided Cold Start Benchmark)

### 1. 结构设计与动机
为追求在单帧与系统级全面超越 Trial 22，构建运动引导空间 SCR 门控残差侧支（`P0ResidualHighway` with `spatial_gate_net`）：
- **动态空间门控掩码**：从输入 $x$ 的短差分与时域中值残差（通道 1 & 2）提取局部时序能量变化，在 320x320 尺度由轻量级卷积网络生成动态置信掩码 $M(x, y) \in [0, 1]$；
- **计算公式**：
  $$\Delta F_{\text{guided}} = \alpha \cdot M(x, y) \odot \text{Proj}(\text{MaxPool}(\text{DWConv}(\text{Stem}(X))))$$
  在静态地表、大面积高频晃动杂波和传感器固定条纹区，空间掩码置零阻断虚警；在离散点冲激区域放行增益；
- **训练模式**：底模 Trial 22 100% 物理冻结（1.79M 参数），侧支 1,954 参数从零纯净协同冷启动（`p0-weights=""`，`gate` 零初始化，8 Epochs）。

   - 这 58 处响应在接入后处理双向时空平滑插补后，孤立随机噪声会被运动学滤波自然剔除，而连续物理轨迹将被有效缝合，工程价值远超微小的离散误报代价。

## 五、演进避坑戒律与推广指南

1. **戒律一：严禁越级解冻底模**
   在残差侧支未充分收敛前，严禁为了“端到端联合训练”而提前解冻底模。若后续确需联合微调，必须采用两阶段：Phase 1 冻结底模训练侧支 6 轮，Phase 2 以极微学习率（$lr \le 10^{-6}$）微调最后 2 轮；
2. **戒律二：严禁新增未经门控的特征相加**
   任何新分支与成熟骨干融合，必须显式配备可学习标量门控（$\alpha \cdot \Delta F$）且强制零初始化；
3. **架构推广准则**：
   后续若引入局部自注意力（Spatial Attention）、高通顶帽残差（Top-Hat Residual）或多时相差分特征，一律严格套用本“渐进式微调范式”，以不到 1% 的参数增量实现性能的安全上行。
