## 二、难例逐项深度复盘与交付建议

### 1. DJI_0175_2（临界过渡型）
- **物理现象**：无人机在平坦空域飞行，但因机体姿态偏转、红外辐射反射角改变，频繁出现 1~3 帧微弱暗化，单帧热图峰值在 0.06~0.15 浮动。
- **解决方案**：双向时空平滑（`eval_bidirectional_track_fusion.py`）依靠成熟长航迹进行受控双向动力学插值与碎片缝合，以 **98.07% 超高精确率** 斩获 254 帧命中。

### 2. wg2022_ir_011_split_03（弱脉冲型）
- **物理现象**：目标尺寸极小（仅 1~2 像素），背景极其干净，但由于高斯核能量集中在单像素，未能积累足够的激活响应。
- **解决方案**：放宽空域打捞门限至 `th_salvage=0.06`，配合前缀回填机制（Prefix Recovery），将原本丢失的航迹初始帧全部打捞，召回率突破 55.98%。

### 3. DJI_0051_2（抖动杂波淹没型）
- **物理现象**：云台剧烈颠簸平移，导致地表静态房屋与树木在差分图上形成严重拉扯白边，单帧产生 270+ 虚警，在全图竞争中压制了微弱无人机。
- **解决方案**：离线 GMC（SparseOptFlow 稀疏光流仿射配准）使历史帧与当前帧严格像素级对齐，假警从数学机理上消除，单序列假警从 72 砍至 23（降幅 68%）。

### 4. wg2022_ir_020_split_03（终极极限型）
- **物理现象**：目标局部信噪比 $\text{SCR} < 1.0$，幅度甚至低于探测器焦平面热噪声，单帧和短时差分在信息论上数学不可分。
- **解决方案**：
  1. **物理层中值残差**：21 帧时域中值滑动建模将静态本底噪声压低 $\sqrt{N} \approx 4.5$ 倍，使慢速目标对比度提升到 15~33 灰度级，实现单帧首次破零（命中 58 帧）；
  2. **交付策略**：在技术协议中将此工况界定为“超出单通道光学探测器物理包线（SCR < 1.0）”，系统后端挂接动态规划 TBD 作为长时相干搜索模式交付。
