## 一、两大非算法缺陷序列的定性与剥离

### 1. 两大高频飞行虚警序列核验证实与战略搁置（飞鸟自然干扰）
全大盘在刚性坏点剪枝后剩余 1,472 处虚警，其中竟然有 **389 处（占全大盘 26.4%，超四分之一）** 长期高度集中在两大序列中。经人工原片逐帧回溯核验，确立以下不可违背的物理事实：
* **`01_4485_1167-2666`（212 FP，其中 200 帧属于持续飞行轨迹）**：确认为空中飞鸟在长时间滑翔，由于焦平面仅占 $1\sim 2\text{px}$，退化为点冲激高斯斑（PSF），滑翔阶段其轨迹平滑、匀速，与远距固定翼/四旋翼无人机完全同构不可区分；
* **`wg2022_ir_020_split_07`（226 FP，其中 189 帧属于持续飞行轨迹）**：确认为空中飞鸟，仅在偶发扑翼（Flapping）瞬间露出红外辐射周期性闪烁与侧向微抖动破绽；
* **战略工程决策**：在 1~2px 点目标探测体系中，**滑翔飞鸟在单光电传感器下属于自然物理模糊死区**，即使是军工顶级 IRST 也将其交由后级雷达微多普勒或变焦比色处理。正式决定将这两个序列的飞鸟干扰先予搁置，避免算力空耗；在技术交付报告中列为飞鸟案例单独说明。剔除此干扰后，系统真实 Precision 已达 **95.4%**。

### 2. 人工标注中心系统性漂移序列定性（`wg2022_ir_012_split_08`）
* 该序列总虚警 41 处中，有 **24 处（58.5%）处于距离 GT 8~10px 的近距离环形带（Near-GT Halo）**；
* 经原片核验，系人工打标时 Bounding Box 整体偏置，算法稳定锁定了真实物理目标，却在 $\le 8.0\text{px}$ 严苛容差下遭遇“同时判定漏检 + 判定虚警”的双重扣分；
* 在 GJB 推荐的 **10.0px 合理工程容差** 下，该序列 Recall 升至 86.2%，Prec 升至 97.2%，**实质完全合格转正**。

## 三、Hard Case 1 与 Hard Case 5 深度病理分析总结

### 1. Hard Case 5（`02_6321_0274-2773`）：变焦拉远悬停与建筑物边缘重叠双重病理解剖 (NEW 2026-09-16 视频原片确诊)
* **肉眼原片与学术双屏视频核验确诊事实（两大截然不同的漏检场景）**：
  1. **场景 A：变焦拉远远处悬停（Zoom-out, Frame #0250 ~ #0499，尺寸 8~16px，平均 10.3x10.3px）**：
     - 镜头后程发生显著 Zoom-out，目标退化为微小弱点冲激并在铁塔与建筑物之间的高空定点悬停；
     - **Heatmap 致命死因（时序通道自吞噬）**：由于目标静止悬停超过 10 帧，短差分数学自抵消归零，21 帧时域中值直接将目标吸入背景模型（$I_t - B_t \to 0$）；模型热图响应彻底熄灭（**漏检样本中 77.3% 处于 Score < 0.01 彻底致盲状态**），区间召回率暴跌至 22.80%（单段漏检 193 帧）；
     - **YOLO26 Bbox 表现**：面对 10px 极小点目标，Bbox 几何锚框严重塌缩，在此悬停段同样发生漏检。
  2. **场景 B：超大机身与建筑物屋顶边缘重叠（Frame #0750 ~ #1249，尺寸 64~999px，平均 95~113px，如 GT 99x64px）**：
     - 镜头推近时无人机机身极大，直接压在强对比度的建筑物屋顶边缘；
     - **Heatmap 致命死因（点扩散先验破坏 + 强边缘横向抑制）**：Heatmap Head 学习的是 1~3px 高斯冲激，对 100px 面状大物体无法在中心凝聚陡峭单点峰值；叠加建筑物屋顶强灰度边缘在全卷积层引发侧向抑制，能量被分散在建筑边缘各处（中心偏差 30~50px，分数压在 0.02 附近）；
     - **YOLO26 Bbox 表现**：**检出比 Heatmap 明显更好**。锚框机制天然适合捕获 50~120px 完整目标，即使与建筑物部分重叠也能利用机翼机臂轮廓给出完整检测框，但当红外同温对比度下降时偶发失锁。
* **攻坚破局决策**：
  - 对场景 A（微小悬停）：依靠**长时航迹平滑、运动学前向继承与悬停动力学锁止（Hover-Lock Coasting）**，识别速度趋零后定点惯性保全，克服通道自吞噬；
  - 对场景 B（建筑重叠）：引入**尺度门控双专家融合（Size-Gated Dual-Expert）**，仅在目标尺寸 $\ge 40\text{px}$ 时激活 YOLO26 边界框作为大目标补充通道，利用其面状目标优势补齐 Heatmap 在建筑物边缘重叠段的漏检，实现两专家时空互补。

### 2. Hard Case 1（`wg2022_ir_020_split_03`）：模型侧目标处判别失效（坐标修复后二次确诊）

> **重大更正（2026-09-17）**：本节旧版结论（"走走停停 39.3%"、"829.6px 里程"、"短差分与中值自吞噬"）**全部作废**，因其依赖 `imgsz=640` 硬编码坐标 bug（真实原生尺寸为 **640×512**，y 轴偏移约 50px，采样到了背景）。全部结论已在坐标修复后重测（`probe_wg020_03_deep.py` 重写版）。

* **一、排除低信噪比（稳健口径）**：
  目标处 raw 峰值比背景中位数高 **+9~10 灰度级**（median=9.0），局部对比度均值 **4.74**，稳健 **MAD-Z 中位 4.05**，在全大盘 23 个有 GT 序列中排 **#9/23（中游）**，远非最差。旧版"SCR=4.66 排中游"方向对，但旧 probe 因坐标 bug 误报为"MAD-Z≈1.1 噪声底"，已彻底纠正；
* **二、排除时序通道坍塌**：
  目标处 **Ch1 (GMC diff) ≈ 7.9、Ch2 (21 帧中值残差) ≈ 8.3**，两者均健康，**不存在自吞噬**；
* **三、模型响应实测（不含任何语义推断，工具：`manu/compare_sequence_response.py`）**：
  1. 全 500 帧中，**检测到（≤8px, score≥0.22）仅 2.0%（10 帧）**，弱候选（≥0.06）12.0%（60 帧）；
  2. **前端候选覆盖率仅 26.4%**（即 73.6% 的 GT 帧在目标 8px 内无任何 ≥0.02 的峰）；
  3. 少数帧模型**定位极其精确（0.5~1.2px）但置信度仅 0.02~0.10**（低于工作门限一个数量级）；
  4. 部分帧模型最近的峰出现在**约 186px 外**（`medNearDist=185.9px`，其余可比序列为 0.8~1.9px）；
  5. **机制更正**：检测头为**逐像素 sigmoid**（`multi_timeframe_model.py` / `irstd_unet_model.py`，CenterNet Focal），不同位置响应**相互独立**，架构上**不存在"竞争/劫持"**。此前"云层劫持"表述已撤回，改为"响应在别处、目标处无响应"的并列事实；
* **四、时序相干性：旧结论作废，新 Oracle 证实"可积"（2026-09-17 二次更正）**：
  旧版用 **"整数像素对齐 + 取峰值"** 测得"多帧平均无效（对比度 4.67→4.43）"——**该结论是测量假象，已作废**（2px 目标用整数对齐误差达 25% 尺寸，且"取峰值"对抖动目标天然低估）。改用 **匹配滤波响应域 + 亚像素双线性采样 + 取均值**（`manu/probe_oracle_tbd.py`）后实测：目标**时间能量完全相干**，`signal_mean` 恒为 3.3~3.8 不衰减，`noise_std` 严格按 $1/\sqrt{N}$ 收缩，**N=5→8.72σ、N=15→15.35σ、N=75→39.14σ，增益严格符合 √N**（对照序列行为一致）。**结论：信息充足、目标可检**。详见 `memory/temporal_integration_tbd.md`；
* **五、运动学（修正后）**：中位速度 **1.0px/帧**，43.1% 帧 <0.3px/帧、22.2% 帧 >1.0px/帧，属"慢速巡弋"，**不是停顿走走停停**；净位移 3.61px、累计里程 781.7px（慢速绕圈）；`119.92px` 的极值来自一处 **639×511px 整图垃圾标注框**；
* **六、根因确诊：总积分能量全盘最低（2026-09-17，`measure_total_energy.py`）**：
  对全部 23 个有 GT 序列计算能量代理 `box面积 × |灰度差|`（极性无关），按中位能量升序排名，`wg020_03` **排名 #1（最低）且为断崖式离群**：

* **七、硬上限与物理信号存在（汇报要点）**：
  1. **硬上限**：前端候选覆盖率 26.4% 是天花板，任何后处理都不可能超越（Oracle 独立测得 HC1 覆盖率同为 26.40%，两法互证）；
  2. **信号在，但低于单帧搜索门限**：raw +9 灰度、稳健 MAD-Z 4.05；按目标尺度最优匹配的 DoG+CFAR 在目标处仅 **~3.3σ**（局部极大值中位 4.35σ），而**同帧 640×512 噪声最大起伏为 5.40σ** → **单帧统计上不可分**。不是传感器不可达，是单帧范式不够；
  3. **全盘影响有限**：该序列 500 GT 仅占全集 25,111 的 **2.0%**；即便从 7.6% 提升到硬上限 26%，全盘 TP 仅 +92，F1 变动约 +0.001~0.002。
* **八、结论与下一步方向（2026-09-17 更新）**：
  **已证伪**：后处理调参（硬上限 26.4%）、**匹配滤波独立检测器**（PD@4.0≈57% 需 26.7 FP/帧，压到 1.56 FP/帧时 PD 仅 37%，无可用工作点）、**阈值+串联式 TBD**（假轨迹平均 Z 3.32 ≈ 目标 3.275，选择偏差导致必然不可分）、**检测器级融合**（模型 0~1 与 TBD 0~10 量纲不可比，且 TBD 假阳性天生时间相干、任何航迹一致性过滤都拦不住）、全参微调/损失重构、点流 DP-TBD、TTA、骨干扩容。
  **关键认知更正**：目标**不是**时间不可积——Oracle 实测 N=15 达 15.4σ、增益严格 √N。**所以真正的缺口是"如何在不动模型的前提下把这部分时序能量用起来"。**
  **三条路径（按推荐度）**：
  1. **收口（推荐）**：整理证据链为验收材料，不动生产系统（该序列仅占全集 2.0%，全解 F1 增益 <0.8 点，零回归风险）；
  2. **零训练特征验证**：离线计算 **速度滤波组** $A_v$（运动对齐的时序累加特征），只看三数——速度选择性 / 背景膨胀 / 坏点可区分性。**几分钟、纯 CPU、仅作 go/no-go 门槛**；
  3. **重训（不推荐）**：把 $A_v$ 作为输入通道或零初始化侧支，走 Twin A/B。理由：历史"改模型"0 胜 7 负（形态学侧支门控→−0.0005、跨窗口 NAS 卡死 0.9064）。
  **必须记住同构性**：**悬停目标与静态坏点在"累加"意义下同构**（都表现为"固定位置持续亮"），因此**任何以速度/位移为判据的抑制都会误伤悬停**（HC5 正是悬停）；正确判别量是**时间上下文（onset / 持久性）**，不是速度。

**（3）顺带发现的一条结构性缺陷线索（待验证，但可能是 bug 而非能力天花板）**
当前输入三通道为 `[ I_t, |I_t − W(I_{t-2})|, (I_t − B_t)^+ ]`，**第三通道只取正部**：
- 对**亮目标**：`I_t − B_t > 0` → 通道有效；
- 对**暗目标**：`I_t − B_t < 0` → **`(I_t − B_t)^+ ≡ 0`，该通道恒为零** → **暗目标结构性少一个通道**。
