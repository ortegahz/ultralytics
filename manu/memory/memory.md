## 一、算法演进全景脉络 (Evolution Roadmap)

全周期算法演进划分为四个核心阶段，完整记录“设想 $\to$ 验证 $\to$ 定性/扬弃”的闭环：

```text
阶段一：数据与单帧检测器选型 (Nodes 1-4, 6, 7, 14)

  -> YOLO26 框架选型与 Baseline (标准 Anchor/Bbox 塌缩)
  -> P2 极小特征层引入 (Stride=4, 160x160 特征图)

  帧差输入 (FD 3 通道 [I_t, |I_t - I_{t-1}|, |I_t - I_{t-2}|])
  -> 辅助位移矢量多任务联合预测 (缺乏密集位移标签，梯度震荡证伪)
```

## 五、骨干容量扩展总结与下一阶段单帧演进重心 (Scale Conclusion & Next Roadmap)

### 1. YOLO26s 容量探索终局定论 (Scale Up Done & Concluded)
通过【官方权重 P2 5-Epoch 对照】与【P2 底模热启动 P1 8-Epoch 深入实测】，确立以下不可违背的技术定论：
- **容量收益的物理边界明确**：Small 骨干增加的通道宽度能够极其显著地抑制地物晃动与复杂边缘，将验证集虚警从 3,572 锐减到 **1,638**，Precision 突破 **92.03%**；
- **小目标几何缺失阻断了 Recall 收益**：红外弱小目标在焦平面仅占 $1\sim 3\text{px}$，属于二维光学冲激响应（PSF），缺乏内部几何部件语义。在小样本与高分辨热图的 100,000:1 极端负样本背景下，更大参数量诱发了“过度自信抑制”，工作门限被死死锁在 **0.45~0.50**，Recall 停留于 75.33%（距 Trial 22 的 86.11% 存在 11% 鸿沟），单帧 F1 终局停在 **0.8285**；
- **工程决策**：**正式终止对纯骨干尺度扩展（YOLO26s 深训）的算力投入**。

### 2. 单帧极限与新突破方向定性 (Single-Frame Limit & Next Roadmap)
通过【TTA 热图软融合实测（F1 仅由 0.9057 微增至 0.9070，th=0.25 下弱目标反而丢失）】，彻底确立以下底层规律：
1. **单帧几何扰动对点冲激目标的局限**：红外弱小目标（1~2px）无内部语义部件，水平镜像翻转不产生信息增量；双视图概率软平均（mean）反将处于临界线上的微弱冲激拉低，引发同阈值下的漏检；
2. **单帧物理极限已达**：在 $[I_t, |I_t - W(I_{t-2})|, (I_t - B_t)^+]$ 数据管道下，Trial 22 纯单帧模型的 F1=0.9057（Recall 86.11%, Prec 95.51%）已逼近单帧信息论极限，单纯靠测试期几何平移平均无法实质拉大 SCR；
3. **后续单帧网络突破聚焦**：
   - 若继续主攻单帧内部优化，重心应从“外部变换/加宽骨干”转向**【监督信号构造：正样本近邻自适应软化 Focal Loss（Gaussian Relaxation）】**，消除网络对微弱弥散冲激的过度压制；
   - 若系统级追求大盘突破，最高交付基准依然是经过事实检验的**【双向时空平滑插补系统（F1=0.9154 SOTA）】**。

## 六、重大非继承性改动方法论标准 (Twin A/B Controlled Protocol)

### 1. 核心问题与方法论陷阱警示
- **基线混淆假象（Baseline Confounding）**：当前最高 SOTA 模型 `Trial 22` 拥有极其深厚的血统红利（红外专训底模先验 + 100+ Trial 的 Optuna 超参黄金偏置）。
- **严重避坑准则**：任何**无法继承 SOTA 权重的重大改动**（如输入通道数量与编排变动、新 Stem 模块引入、主干尺度扩展、局部注意力机制替换等），**严禁直接与当前 SOTA 模型对比**！
- **惨痛教训**：若将仅冷启动训练 3~5 轮的新方案（F1 约 0.84~0.86）直接与 Trial 22（0.9058）对比，必会导致潜在的革命性特征因“训练不充分/超参未适配”而被轻率误杀证伪（如历史 Top-Hat 零训练探针）。

### 2. 重大改动准入标准：同源双胞胎受控 A/B 协议 (Twin A/B Test)
对任何破坏权重继承的实验，必须强制执行单一变量受控协议：
1. **同基座对照**：
   - **对照组 A (Baseline Twin)**：现有成熟架构，采用官方自然图像权重冷启动；
   - **实验组 B (Target Twin)**：待验证新结构/新通道，采用相同官方自然图像权重冷启动；
2. **同环境受控**：相同的训练轮数（严格锁定 5~8 Epochs）、相同的学习率与 Schedule、相同的数据集管道与随机种子；
3. **晋级判定准则**：
   - **若 $F1_B > F1_A$**：证明新架构/新特征具备底层表征优势，正式立项，投入算力进行充分预训练与超参搜索去冲击总大盘 SOTA；
   - **若 $F1_B \le F1_A$**：证明新方案在同等算力预算下收益为负或引发信息混叠，此时定性“证伪”才具备坚实的数学事实依据。

### 3. 历史误判重审与解冻候选池 (Re-examination of Falsified Archives)
根据 Twin A/B 受控协议，对历史 8 项证伪实验进行严格的“方法论合规性”复核，正式确立两项实验的解冻与重审标准：
1. **空时双残差 Top-Hat 空间残差（正式从死刑解冻，列入高优先级候选池）**：
   - **历史误判本质**：当时直接用改了通道的数据喂给原图训练的 Trial 22 进行零训练直接推理，因直流基底断崖式塌陷 70% 导致 F1 虚假暴跌至 0.5932。这属于典型的测试方式不当，而非特征本身无效；
   - **重做准则**：后续若针对 `DJI_0051` 地表杂波再度攻坚，应按照 Twin A/B 协议：对照组 A `[I_t, Diff, Median]` vs 实验组 B `[Top-Hat(I_t), Diff, Median]`，均从官方权重冷启动训练 5 轮，以公正裁决顶帽滤波对红外背景抑制的真实物理效用。
2. **PixelShuffle 亚像素解码（解冻为结构级可选组件）**：
   - **历史误判本质**：当时在完全收敛的 Trial 22 关键枢纽处强行插入未初始化的随机卷积微调 2 轮，随机梯度直接冲垮了深层高斯响应先验；
   - **重做准则**：后续若要探索亚像素解码，严禁在收敛权重上生硬替换微调，必须在主干预训练初期（冷启动）一同参与端到端训练，或采用零初始化恒等门控（$\gamma=0$）温和注入。

### 2. 新域四类失败模式与当前判断
人工观察新素材初步发现四类问题：
1. **悬停目标**：GMC短差分趋近零，21帧正残差中值可能把静止目标吸收到背景；悬停与静态坏点在“运动累加”意义下同构，不能简单用速度门限过滤。
2. **暗目标**：当前 `(I_t−B_t)^+` 只保留亮于背景的正残差，对黑色/暗目标结构性不利；反相/双极性残差是待验证方向。
3. **大目标、尤其大悬停目标**：HM略有优势/或与 YOLO26 BBox 接近但仍难检出；更准确的根因是“时序通道因悬停失效”与“训练集大机身空间纹理样本不足”叠加，并非单纯尺寸问题。HM的点冲激范式对大机身多峰、建筑边缘遮挡也天然不利。
4. **极小目标**：总积分能量低、Stride=2采样与噪声峰竞争，属于前端空间响应瓶颈。

当前交付策略倾向：**Trial 0474 HM 作为唯一生产主模型**；比赛数据集上 YOLO26 BBox 对大目标没有稳定超过 HM 的证据，不默认采用双模型融合。YOLO26 BBox 暂保留为预标注的尺寸来源/对照专家，不代表最终生产模型。

### 3. HM 与 YOLO26 BBox 输入契约（必须分开准备）
- **HM Trial 0474**：原生 640×512 灰度帧上在线/离线计算 GMC + 21帧历史中值，模型实际输入按训练契约为 `[(I_t−B_t)^+, |I_t−W(I_{t-2})|, I_t]`，再 gray-114 letterbox 到 640×640。
- **YOLO26 BBox trial_0028**：不使用 HM 的 GMC+中值管道；预标注输入按短时帧差准备 `[I_t, |I_t−I_{t-1}|, |I_t−I_{t-2}|]`，由 Ultralytics BGR→RGB处理保持训练时通道语义。
- 不能把 HM 中值三通道直接喂给 trial_0028；也不能把 BBox短差输入直接替代 HM输入。

### 4. 已确定的自动预标注规则
目标是降低人工标注量，最终仍输出标准 YOLO `class cx cy w h`，坐标归一化到原生 640×512：
1. HM 产生中心点候选，作为预标注主候选池。
2. 若 HM 点**落入**某个 YOLO26 BBox，使用该 BBox，临时类别写 **class 0**。
3. 若 HM 点没有落入任何 BBox，以 HM 热图响应范围粗估一个 bbox，临时类别写 **class 1**。
4. `class 1` 仅表示“HM粗框、待人工复核”，不是最终语义类别；人工确认后全部统一为 class 0。
5. HM漏检的目标不会自动进入候选池，人工必须抽查无候选帧；可选 `--include-bbox-only` 另存 class 2 作为诊断，但默认关闭以遵守“HM主导”。
6. 保留 `provenance_*.json`，记录 `source=hm_bbox/hm_coarse`、置信度、中心与尺寸；不要只依赖临时 class 区分来源。

## 2. 当前绝对最高 SOTA 交付基线 (Current SOTAs)
- **模型只有一个：冻结的 Trial 0474 热图检测器**，多个尺度各跑一次同一模型。**不引入 YOLO26 BBox**——最初误以为"伪标签 = HM+BBox 融合"，被用户纠正；YOLO26 伪标签分支（`preannotate_hm_bbox.py`）是另一条已存在的路线，本脚本与之无关。
- **融合口径完全对齐 `probe_heatmap_regions_video.py --fusion-row`**：每个尺度的热图先按各自的 letterbox/downsample 逆映射回**原生 640×512 网格**，然后 `np.maximum.reduce` 逐像素取最大 → 按 `main_threshold` 二值化 → 膨胀 `fusion_dilate`（默认 9，奇数自动 +1）→ 8 连通域 → `area >= min_area`（默认 4）。**逐尺度行不膨胀**，按 `region_threshold`（默认 0.06）直接连通域。
- 每个检出记录 `(cx, cy, w, h, area, peak, sum)`：坐标为连通域**质心**与外接框，`score = 连通域内热图峰值`，另存热图积分 `sum`（供 memory §十一.2 的 `sum>=15` 能量兜底规则直接使用）。排序按 **sum 降序**（与视频脚本 `entries.sort(key=-sum)` 一致，**不是**按峰值）。
- **Cache 格式**（CSR 布局，避免 165k 帧的 pickle 膨胀）：`frame_index` int32(N,) / `offset` int64(N+1,) / `points` **float32**(M,2) / `sizes` float32(M,2) / `scores` float16(M,) / `sums` float32(M,) / `area` int32(M,) / `tag` uint8(M,)。`tag` = 尺度下标表示逐尺度行，**255 = 融合行**。配 `iter_frames(cache)`。**坐标必须 float32**（第四节第 6 条）。
- **两种输入源**（互斥必选）：`--frames-root`（原始灰度帧现场算 GMC+21 帧中值，与 preannot_v1 特征同源）/ `--features-root`（读已生成特征 JPG，快得多）。后者实测覆盖 `longquanshan_ir_gmc_median` 的**扁平**目录。
- **通道序与 Padding 契约**（沿用并已实测）：落盘序 `[I_t, diff, median]`，**每个尺度**都 `[..., ::-1]` 转成模型序 `[median, diff, I_t]`；`cv2.copyMakeBorder(value=114)` 只填第 0 通道，故原生尺度是 I_t 填 114、median/diff 填 0，与下采样尺度（I_t 填自身均值、median/diff 填 0）一致。
- **实测尺度量化误差**（热图往返，标记点回位偏差）：原生 0.0 px、160 尺度 1.0 px、**80 尺度 4.5 px**。80 尺度下 1 个输入像素 = 8 原生像素，位置量化固有如此，**仍小于项目统一的 8.0 px 匹配容差**，但引用该尺度的坐标时须知其精度上限。
- **并行**：脚本不含调度器，`--shard i/n` 对排序序列取模切分；每序列独立写 `{seq}.pkl` + `summaries/{seq}.json`，无共享 manifest ⇒ 多进程无写竞争。
- ⚠️ `pathlib.glob` 前导 `_` 陷阱：`glob("__frame_*.jpg")` 在特征扁平目录上返回 **0**，必须写 `"*__frame_*.jpg"`。已用两种真实布局交叉验证：24 序列 / 165,223 帧一一对应且逐帧索引对齐。

### 5d. 龙泉山 Final_Labels 域全量评测结论：工程交付判据与 7 条 UN-PASS（2026-10-09）

**评测口径与工具**：`manu/evaluation/eval_multiscale_cache_th.py`（纯 CPU，直读 cache pkl）。关键设计：
- **匹配双口径**：`--match-mode dist`（中心距 ≤ `--tol`，与 Anti-UAV 历史可比）/ `inbox`（预测中心落入 GT 框）。GT 存完整 `(cx,cy,w,h)` 原生像素。

- **FN 拆解**：`fn_absent`（附近完全没检出 = 前端召回上限）/ `fn_compete`（有合格检出却被更高分抢走 = 合并/重复抑制代价）。**这是判断半径是否过大的唯一依据**：半径增大而 F1 上涨但 `fn_compete` 同步上升 = 靠吞真目标换来的假涨。

### 6. 交付训练与验证决策
- 交付前先完成：全量新视频人工复核后的标准 YOLO bbox + 场景/难例信息（可作为 sidecar，不必成为训练类别）。
- Zero-shot阶段：先固定 HM单模型基线和（仅作为对照的）HM+BBox预标注融合规则，统计整体及暗/悬停/大/极小目标分桶结果，再建立 hard-case 台账。
- 通过视频仍有训练价值：提供新域正常外观、背景负样本与压缩/插值域适应，防止只训难例造成虚警和遗忘；但不能全部占据训练集。
- hard case 的研发评估：不能把唯一 hard case 同时作为训练和独立测试；可采用留一 hard case 评估泛化。最终交付版在超参固定后可以把全部 hard case 加入训练，但此后只能用原始 val和未参与最终训练的新域视频做回归，不能宣称这些 hard case 是未见泛化测试。
- 推荐最终流程：原始 train + 新域部分通过视频 + hard case（过采样）训练；新域部分通过视频留作回归；原始 val 永不加入训练；每 epoch 检查原始 val Precision/F1 与新域分桶 Recall。
- 新域增广训练与过去“改变输入通道”的实验不同：若保持 Trial 0474 三通道语义和结构不变，可以尝试受控低学习率全参域适应；仍应优先保留 Trial 0474 冻结基线、原始 val 回归闸门和 Adapter/冻结侧支备选。

### 4. 黑热模式 Handle 实验（重要新增结论）
- 新业务中的 `VIDEO00032_19700101_014453` 观察到目标为**黑热模式**：目标相对背景呈暗目标，而 Trial 0474 训练域主要按白热正残差建模。
- 结构性原因：当前第三通道为 `(I_t-B_t)^+`，只保留亮于背景的正残差；黑热目标在原灰度极性下使该通道响应显著减弱甚至接近零，导致时域特征少一类有效证据。直接把已生成三通道中的某一通道反相是不正确的。
- 正确 Handle 是在原始灰度帧级别做极性转换：`I'_t = 255 - I_t`；然后**从反相后的完整帧序列重新计算** GMC 两步差分和 21 帧时域中值残差，形成同一训练契约的三通道 `[I'_t, |I'_t-W(I'_{t-2})|, (I'_t-B'_t)^+]`，再送入冻结 Trial 0474。
- 已新增一体化实验脚本：`manu/videos/run_whitehot_sequence_paper_video.py`。默认处理 `VIDEO00032_19700101_014453`，不修改原始帧，执行：黑热逐帧反相 → GMC+21 帧中值特征生成 → Trial 0474 batch 推理 → 生成论文式诊断视频。输出目录默认是 `/mnt/data/siping/datasets/manu/longquanshan_whitehot_VIDEO00032_19700101_014453/`，视频位于其 `paper_diagnostic/` 子目录。
- 该脚本默认右侧显示合成 HM、左侧显示 Ch0 原始红外和局部 RAW/CLAHE 放大；使用 `--right-panel features` 可改为四宫格输入特征显示。反相版本的原始帧和特征均独立保存，便于复核。
- 当前“黑热转换后大幅提升召回”只是视频人工观感，**尚无人工 GT 支持的定量 Recall/Precision/FAR**，不得写成正式指标。下一步必须优先标注该视频或至少抽取连续代表片段做人工 GT，对原始黑热输入与反相输入做同一帧集合 A/B：Recall、Precision、FAR、连续漏检长度、目标处 HM 分数。

- 只有在以下情况成立时才进入微调：① 黑热模式无法可靠获得或存在错判；② 反相不是严格灰度极性转换（存在 LUT、伽马、动态范围差异）；③ 多个独立黑热视频经反相后仍达不到工程验收阈值。届时保持三通道语义和模型结构不变，优先做冻结底模/Adapter 受控微调；原 Anti-UAV 4th val 必须作为不可退化闸门。
- 当前推荐生产策略：`mode=white_hot` 直接使用原始 Trial 0474；`mode=black_hot` 先逐帧反相，再重新生成 GMC+Median，不允许把黑热原图直接喂给白热特征管道，也不允许只反转输出 HM 或已生成的单一通道。

### 5. 新增业务 Hard Case：下沉入地/入城导致目标被地表杂波淹没（2026-09-28）

- **现象定义**：无人机从天空背景向建筑、道路、楼顶、电线塔等复杂地表区域下沉或入城后，原本可稳定跟踪的目标出现连续漏检、热图峰值降低、峰值粘连边缘或航迹中断。该问题与黑热、悬停、近距大目标不同，是典型的**天空到地表背景跃迁失效**。
- **待确认的首要分叉**：必须先检查临界段单帧 Trial 0474 热图和三通道响应，判断目标是：
  1. 前端响应完全消失/接近零（候选池死区）；
  2. 仍有微弱残存峰值但低于 `th_base=0.22`，可在 `th_salvage=0.06` 附近打捞；
  3. 响应存在但被城市边缘峰、配准毛刺或错误局部极值吸引。
  在完成该分叉前，不得直接选择降门限、边缘抑制或时空累加方案。
- **候选物理机理（待定量验证）**：
  1. 城市建筑边缘、窗格、道路和高温反射面使局部背景方差上升，目标 SCR/总积分能量相对下降；
  2. GMC 存在亚像素残差时，楼顶线、外墙和高压线等高对比结构会在 `(I_t-B_t)^+` 中形成强几何毛刺；
  3. 目标与建筑边缘粘连后，点目标的近似对称高斯形态被破坏，热图能量可能弥散、偏移或形成多峰；
  4. 连续漏检超过 `infill_gap=3` 和 `stitch_gap=4` 后，天空段稳定航迹会断裂，后处理无法仅靠短缺口插补恢复。
- **优先验证证据链**：沿下沉临界段逐帧记录 GT 位置附近的 Ch0/Ch1/Ch2 值、热图最大值、目标邻域峰值、最近背景峰距离、GMC MSE/Inlier Ratio、目标与强边缘的距离，以及连续漏检长度；同时与同一序列进入地表前的天空段作配对 A/B。所有采样必须使用原生图像坐标，缓存预测必须使用 Letterbox 坐标，禁止混用。
- **候选防御方向（均未证实）**：
  1. **航迹牵引保护**：根据进入地表前的速度/加速度和预测位置，在确认航迹进入复杂地表ROI时启用短时软保护或区域性低门限；不得让未经确认的杂波轨迹获得同样权限；
  2. **边缘感知残差抑制**：利用 Sobel/Canny/Hessian 或局部梯度统计，抑制由GMC微小残差触发的地表强边缘毛刺；必须验证不会抹掉真实点目标；
  3. **运动管道软状态积分**：保留低于 `th_base` 但高于噪声基底的候选，在已有航迹的运动管道内进行受控累加；严禁采用无门控的低阈值点流DP-TBD，历史实验已证明会造成虚警雪崩；
  4. **GMC健康度降级**：若配准残差异常，静音 Ch1/Ch2 或切换灰度分支，避免错误时序通道放大地表边缘。
- **工程定位**：新增优先级为 **P1（紧接黑热/GMC健康度之后）**。需建立独立的 `urban_sink/ground_entry` 业务分桶，统计 Recall、Precision、FAR、连续漏检长度、航迹中断率、恢复延迟和误保护率；在通过同帧业务域 A/B 后，仍须通过 Anti-UAV 原始验证集不可退化闸门。

## 十、领域迁移 Bad Case 全景与工程解法候选（2026-09-24）

> 本节记录实际业务数据评测与迁移落地阶段发现的八类核心失效模式。除已完成的输入契约与工程规则外，下列解法均应视为工程候选方案，必须经过同一数据集上的 A/B、定量指标和回归闸门验证，不得直接写成已证实收益。

### 1. 红外极性切换：黑热模式（P0，前处理）

- **现象**：目标由亮变暗后，Heatmap 响应极低，召回显著下降。
- **机理**：Trial 0474 的第三通道为 `(I_t-B_t)^+`，黑热目标的负残差被 ReLU 截断；同时 GMC 差分和白热训练先验发生极性失配。
- **候选解法**：有可靠机载模式元数据时，在原始灰度帧级执行 `I'_t=255-I_t`，再从完整反相帧序列重新计算 GMC、21 帧中值和三通道输入；无元数据时可研究基于全图统计的极性识别，但误判风险需单独验证。
- **工程边界**：不能只反转已生成的单一通道、HM 输出或直接把黑热原图送入白热管道。当前反相收益仍需人工 GT 定量确认。

### 2. 悬停无人机（P1，背景建模与后处理）

- **现象**：减速或悬停后差分线索消失，连续漏检。
- **机理**：目标停留时间超过 21 帧后可能被吸入时域中值背景；通道 2 接近零，通道 3 发生自消隐，仅剩弱灰度通道，后处理又可能将其当作静态噪声清除。
- **候选解法**：对已有高置信航迹启用悬停态保护，并在预测位置局部窗口（例如 15x15）内冻结背景更新，保留悬停前背景作为参照。
- **工程边界**：必须防止把固定坏点、热斑或杂波冻结为目标；应先做局部背景冻结的误报/漏报 A/B。

### 3. 近距离大目标：Heatmap 多峰分裂（P2，Heatmap 后处理）

- **现象**：机体变大后出现多个局部峰，被输出为多个目标或重复虚警。
- **机理**：模型主要由 1~3 像素点目标热图先验形成，电机、机臂等高热部位可分别激发局部极大值，超出常规点峰抑制半径。
- **候选解法**：对近距离峰值进行自适应空间聚类；对距离不超过约 12 px 且具有连通响应能量的峰，基于连通域加权质心合并为单一中心。
- **工程边界**：阈值必须按目标尺度和场景标定，避免把相邻真实无人机合并。

### 4. 近距离大目标：Bbox 检测器大面积漏检（P1，输入旁路与轨迹层）

- **现象**：传统 Bbox 检测器迁移到业务数据后仍对大目标大面积漏检。
- **机理**：大目标帧间重叠造成差分自抵消，通道呈中空边缘；红外机体还可能表现为孤立电机热斑与暗弱机身，难以在 640 尺度形成闭合刚体轮廓。
- **候选解法 A**：建立不修改 Trial 0474 底模的旁路，使用原始单帧灰度图下采样至 320x320，交给独立轻量 Bbox 检测器。
- **候选解法 B**：在 Track 层利用多个点目标的同速运动和相对距离稳定性，反向聚类拟合整体大目标。
- **工程边界**：A/B 均属于待验证旁路，不得默认替代 Heatmap 生产模型；需要评估计算量、误报、目标身份一致性和跨场景泛化。

### 5. 探测器 NUC 温漂与固定条纹（P1，前处理）

- **现象**：底色漂移、垂直或水平固定条纹增加虚警，并淹没暗弱目标。
- **机理**：未充分快门或两点校正时，焦平面固定图案噪声破坏 GMC 配准和时域中值背景建模。
- **候选解法**：增加轻量列固定图案噪声去除，按列统计抑制纵向条纹；配合适度 CLAHE 恢复局部对比度。
- **工程边界**：前处理必须保持训练输入的灰度动态范围和三通道语义，先验证 GMC 内点率、背景残差和原始 Anti-UAV 回归指标。

### 6. 镜头水雾与油污退化（P2，部署参数与后处理）

- **现象**：目标被散射模糊，Heatmap 峰值变钝并低于当前门限。
- **机理**：光学散射将目标能量空间展宽，单帧响应低于 `th_salvage=0.06`。
- **候选解法**：研究恶劣天气参数包，将 `th_base` 降至约 0.15、`th_salvage` 降至约 0.03，同时提高 `min_hits_infill`、加严航向角变化等时序约束。
- **工程边界**：降低门限必须与连续性约束联动，单独降门限会放大水雾纹理和白噪声虚警。

### 7. 吊舱平台大动态机动（P0，GMC 与特征合成）

- **现象**：云台转动、快速回中或变焦时，GMC 漂移并出现全屏差分虚警。
- **机理**：单应性模型无法拟合大视角转动、近景视差或快速变焦，配准残差在通道 2、3 中被放大。
- **候选解法**：实时监控 GMC 单应性残差 MSE、内点率等健康度指标；超过阈值时动态静音通道 2、3，降级为纯单帧灰度模式。
- **工程边界**：降级期间需要明确恢复条件和告警机制，避免平台短暂机动造成长时间失去时序特征。

### 8. 野外复杂热杂波（P1，运动学后处理）

- **现象**：树木摇晃、岩石和地表热斑持续激发高响应伪峰，虚警增加。
- **机理**：局部热斑与点目标在外观上相似，但杂波通常原位往复振荡，缺乏无人机的单向连续位移。
- **候选解法**：增加运动学曲折度剪枝，计算轨迹净位移与总路程之比 `R=net_displacement/total_path`；对低 `R` 轨迹结合 `min_rigid_disp` 和空间方差约束进行剪枝。
- **工程边界**：对盘旋、变向和短航迹目标可能误伤，阈值必须按目标运动类型分层验证。

### 9. 下沉入地/入城导致地表杂波淹没（P1，天空到地表背景跃迁）

- **现象**：无人机从天空进入建筑、道路、楼顶或高温地表后，原本稳定的检测/航迹出现连续漏检、热图峰值下降、目标与边缘粘连或航迹中断。
- **候选机理（待验证）**：城市局部背景方差和高频边缘使目标SCR/总积分能量相对下降；GMC亚像素残差在楼顶线、窗格、电线塔等强边缘上形成时域中值残差毛刺；点目标高斯形态被边缘破坏，热图可能弥散、偏移或多峰；连续漏检超过 `infill_gap=3`/`stitch_gap=4` 后，后处理无法仅靠短缺口恢复。
- **首要诊断分叉**：沿下沉临界段检查原生坐标下的 Ch0/Ch1/Ch2、热图最大值和最近背景峰，确认目标是完全无峰、仍有低于 `th_base=0.22` 的残存峰，还是被边缘峰吸引。未完成该分叉前，不得直接降门限或宣称边缘抑制有效。
- **候选解法**：已确认航迹进入地表ROI后的短时软保护/区域低门限；边缘感知残差抑制；基于已有航迹的受控运动管道积分；GMC异常时静音时序通道并降级灰度分支。禁止无门控低阈值点流DP-TBD。
- **验证指标**：单独建立 `urban_sink/ground_entry` 分桶，统计 Recall、Precision、FAR、连续漏检长度、航迹中断率、恢复延迟和误保护率；所有方案仍需通过 Anti-UAV 4th val 不可退化闸门。

### 10. 领域迁移阶段工程优先级

- **P0**：黑热极性对齐、GMC 健康度门控与大动态降级。
- **P1**：下沉入地/入城、悬停保护、大目标输入/轨迹旁路、NUC 条纹抑制、复杂热杂波运动学剪枝。
- **P2**：Heatmap 多峰合并、镜头退化参数包。
- **统一验证要求**：每项方案都必须保留 Trial 0474 原始单帧输出作为对照，使用人工 GT 或可复核标注片段统计 Recall、Precision、FAR、连续漏检长度、轨迹误删率，并通过 Anti-UAV 4th val 不可退化闸门。

### 10. 近距离大目标直接 160 下采样实验（2026-09-24，定性正向）

- **实验背景**：业务域近距离大目标在原始 640x512 三通道特征上经过 Trial 0474 推理时，热图响应容易摊平，单点峰值低于 `th_base=0.22`；此前“下采样后再放大回原尺寸”的低通实验没有明显收益，说明单纯平滑不能解决点目标微架构与大目标尺度失配。
- **实验输入**：直接读取已保存的 `longquanshan_ir_gmc_median/images/train` 三通道特征 JPG，不重新计算 GMC 或 21 帧中值；文件语义为 `[I_t, GMC_Diff, Median_Residual]`，送入模型前保持官方 3 通道 BGR/RGB 通道契约。
- **实验变换**：将整张三通道特征图统一缩小到 **160 px 目标尺度**，保持三通道空间同步后直接嵌入 640x640 输入画布，不再上采样恢复到原始 640x512 尺寸。
  - Ch0（灰度原图）Padding 使用缩小图像边缘灰度均值；
  - Ch1（GMC 差分）Padding 严格为 0；
  - Ch2（时域中值残差）Padding 严格为 0；
  - 避免统一使用黑色或 114 填充造成通道语义错误和人工边缘阶跃。
- **定性结果**：在 `VIDEO00005_19700101_002959` 业务视频上，近距离无人机经过直接 160 下采样与通道感知 Padding 后，原先难以稳定触发的目标出现了**明显且稳定的检出效果**。该现象支持“近距离大目标主要存在尺度/感受野失配，而非完全没有可用目标能量”的判断。
- **当前结论**：该方案是当前近距离大目标的有效候选前处理路线，优先级提升为 **P1**；但目前证据仍是无 GT 视频定性观感，不能宣称 Recall、Precision 或 F1 提升。下一步必须在同一连续帧集合上补充人工 GT 或最小人工框标注，对原始 640 输入与直接 160 输入做 A/B：检出率、连续漏检长度、虚警率、目标中心偏差和响应峰值。
- **工程边界**：该变换会改变目标与背景的空间尺度，不能直接替换 Trial 0474 的原始单帧生产分支；应作为近距离大目标旁路或尺度自适应候选分支，与原始分支进行门控对照。当前脚本为 `manu/diagnostics/probe_heatmap_regions_video.py`，参数为 `--direct-downsample 160`。

## 十一、领域迁移阶段收口总结与交付边界（2026-09-24）

### 1. 当前已形成的闭环判断

- **近距离大目标**：已通过保存的业务域三通道特征做直接 160 下采样 + 通道感知 Padding 的视频定性验证。近处目标出现明显、稳定检出，支持根因主要是 Trial 0474 点目标微架构与业务大目标之间的尺度/感受野失配，而不是目标完全没有输入能量。
- **Padding 契约**：Ch0 灰度通道使用边缘灰度均值或 114 类灰度填充；Ch1 GMC 差分和 Ch2 中值残差严格填 0。禁止三个通道统一填黑或统一填 114，以免引入非物理通道阶跃。
- **黑热模式**：已确认 `(I_t-B_t)^+` 对暗目标存在结构性不利；原始灰度帧反相 `I'_t=255-I_t` 后，重新生成 GMC、21 帧中值和同构三通道管道，是当前正确的 Handle。黑热视频已有定性观感验证，但还没有人工 GT 支持的正式 Recall、Precision、FAR。
- **模型状态**：Trial 0474 单帧基线永久冻结，单帧 F1=0.9064；Trial 0474 加双向平滑、插补和刚性剪枝的系统 In-BBox F1=0.9209。后续领域迁移输入/后处理方案均不能把两者混写。

### 2. 尚未完成正式闭环的工程防御项

- **双尺度生产融合**：160 直接下采样已获得定性正向证据，但 0.5x/0.25x 双尺度并行、主从 NMS、连通域面积/总能量积分以及 `sum>=15.0` 规则尚未完成统一人工 GT A/B 和全盘指标验证。因此当前只能称为候选架构，不能写成“已彻底解决”。
- **吊舱大动态机动**：候选防御为监控 GMC 配准残差 MSE 与 Inlier Ratio；异常帧将 Ch1/Ch2 静音，降级到灰度分支。该策略尚无当前业务数据上的定量回归结果，优先级 P0。
- **NUC 温漂与固定条纹**：候选防御为 GMC/中值前的列固定图案噪声去除和适度 CLAHE。必须先验证不破坏灰度动态范围、通道契约和 Anti-UAV 原始基线，优先级 P1。
- **复杂热杂波**：候选防御为 Track 层曲折度 `R=净位移/总路程` 剪枝，并结合 `min_rigid_disp` 和空间方差约束。需防止误伤盘旋、变向和短航迹目标，优先级 P1。
- **镜头水雾/结露**：候选防御为降低 `th_base` 并同步提高 `min_hits`、航向角变化等时序准入约束；不能单独降门限，优先级 P2。

### 3. 当前交付架构的准确表述

- **冻结底模**：Trial 0474，不进行全参数领域微调。
- **已验证的输入候选**：白热走原始三通道；黑热走原始灰度反相后重新生成三通道；近距离大目标可走直接 160 下采样 + 通道感知 Padding 旁路。
- **待验证的输入防御**：GMC 健康度门控、NUC 列去条纹、CLAHE。
- **待验证的下游防御**：双尺度主从融合、面积/总能量兜底、运动学曲折度剪枝、恶劣天气动态门限包。
- **统一验收要求**：每个候选方案都要与原始 Trial 0474 分支进行同一连续帧集合 A/B，统计 Recall、Precision、FAR、连续漏检长度、中心偏差、轨迹误删率和虚警来源；同时通过 Anti-UAV 原始验证集不可退化闸门。

### 5. 冻结 Trial 0474 的 Wh/BBox 尺寸回归实验（工程可用，2026-09-24）

- **实验目标**：在不改变 Trial 0474 Heatmap 检测输出的前提下，新增轻量 CenterNet 风格 `WhHead`，回归目标中心处的 `log(width)` 和 `log(height)`，为近距大目标多峰融合、Track 关联和尺度分流提供粗略 bbox 先验。
- **训练脚本**：`manu/training/train_trial0474_wh.py`；底模 `runs/optuna_p0_nas/trial_0474/weights/best.pt` 的 Backbone、Neck、P0 Highway、Heatmap Head、Offset Head 全部冻结，仅训练 Wh 分支；使用官方 `uav_gmc_median` 训练/验证数据和稀疏中心点 SmoothL1 监督。
- **四卡训练**：通过 `torchrun --standalone --nproc_per_node=4` 执行，输出 `runs/trial0474_wh/frozen_trial0474_wh_ddp/best.pt`；Wh 分支参数量约 13,954。
- **严格零回归对账**：Epoch 0 对账通过，`Recall=0.861853 / Precision=0.955665 / F1=0.906338 / TP=21,642 / FP=1,004 / GT=25,111`；训练结束再次对账，指标完全保持同一浮点口径，且冻结底模参数与 BatchNorm buffer 未发生变化。与标称 SOTA `Recall=86.19% / Precision=95.57% / F1=0.9064` 的 TP 存在 1 个样本的 DDP 贪心匹配顺序差异，但指标差异小于 `1e-4`。
- **回归收敛**：训练 10 Epoch 后 `train_wh=0.05120`、`val_wh=0.05316`；该损失是中心点处 `log(w), log(h)` 的 SmoothL1，不是像素平均误差。工程诊断同时输出宽/高像素 MAE、绝对误差中位数、相对误差中位数及相对误差在 10%/25% 内的比例。
- **业务域定性结果**：将 Wh 权重接入 `probe_heatmap_regions_video.py`，在保持 `--direct-downsample 160` 的近距尺度旁路下绘制估计 bbox。视频观察表明，bbox 精度不及专用 YOLO Bbox 检测器，但已足以支撑近距大目标区域吸收、多峰点聚合和后续 Track 关联等工程用途。
- **当前结论**：Wh/BBox 回归分支基本达到“粗略尺寸先验可用”的目标，不改变原始 Heatmap Recall/Precision/F1；它不是新的检测器，也不应宣称超过 YOLO Bbox 的 bbox 精度。mAP50-95 作为后续标准 bbox 指标保留，必须以新脚本实际输出为准，不使用此前旧版 AP50/AP90 数值代替。
- **工程边界**：Wh 监督仅在 GT 中心点稀疏计算；推理时从 Heatmap 峰值位置读取尺寸，存在中心偏差导致的邻域外推风险。后续融合需采用 Wh 作为软先验，并与原始点检测分支做门控/主从抑制，不能直接覆盖原始 SOTA 输出。

### 4. 方案 A：原生 1:1 零缩放裁切/双拼（待验证多尺度输入）

- **目标**：在单张 640x640 画布中同时保留原生小目标分支和近距大目标缩放分支，避免对原生 1~3 像素目标做任何插值变形。
- **区域 A**：将原始 640x512 三通道特征原样贴入画布 `canvas[0:512, 0:640]`，不缩放、不插值，专门保留极小目标的原始像素锐度。
- **区域 B**：将同一三通道特征按严格等比 0.25x 缩放为 160x128，贴入 `canvas[512:640, 0:160]`；40 像素级近距目标在该区域约缩为 10 像素，进入 Trial 0474 浅层感受野的候选尺度范围。
- **区域 C**：其余画布填充必须遵循通道语义：Ch0 灰度区域使用 114 或原图边缘灰度，Ch1 GMC Diff 与 Ch2 Median Residual 严格填 0，禁止三通道统一填黑或统一填 114。
- **坐标映射**：区域 A 输出坐标保持原生坐标；区域 B 输出坐标按 `x_real=4*x`、`y_real=512+4*(y-512)` 反算，并裁剪到原生 640x512 范围。实际融合时需明确画布偏移和 letterbox 坐标空间，禁止直接混用。
- **定位**：这是比“下采样后再放大”更严格的无畸变双尺度输入设计，但目前仅完成几何设计，尚未完成 Trial 0474 接入、Wh/尺寸回归、双拼训练、双尺度融合或人工 GT 定量验证；不得写成已攻克方案。
- **相关后续**：若与新增 Wh Head 结合，尺寸回归只能在标注中心稀疏监督，底模 Heatmap/Backbone 保持冻结；应单独报告 Wh 误差与由 Wh 驱动的多峰融合效果，不能把 Wh 训练结果等同于单帧 F1 提升。
