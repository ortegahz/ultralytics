# NanoBench-T1（微小目标测试集）结果总结 —— 2026-11-10

> **一句话结论**：`trial_0031`（P3 路线，int8 板卡 **19.306 ms**）是**首选量产定板件**。
> 它在 **4~8px 弱小目标档反超 55 ms 的 P1 冻结基线（+2.59 pp）**、**>16px 常规目标 0.9445 稳如磐石**、
> **抗地杂波 T3 虚警砍掉 77%**；唯一让步是 **≤4px 极限点源 −3.12 pp**，
> 而老模型为这 3 pp 付出了 **19.3 ms → 55.5 ms（2.87× 时延、−36.2 ms、50 FPS → 18 FPS）** 的代价。

## 4. 结论与定案

1. **交付件 = `trial_0031`**（权重 `/mnt/data/siping/runs/npu20ms_seed2/trials/trial_0031/weights/epoch20.pt`，
   sha256 `c272bc4d…42bf5`；本地副本 `ultralytics/runs/npu20ms_seed2/trials/trial_0031/weights/epoch20.pt`）。
   - int8 板卡 **19.306 / 19.560 / 19.665 ms**（3 次独立会话，全 <21 ms ⇒ 50 FPS 级）
   - e2e 真机闭环：板上 `e2e_par_demo --native-scale 4` 跑真实 BMP 帧 ⇒ **6 检测 / TP 6 / FP 0 / FP=1.000**
     （默认参数则 96 检测 / FP 90 ⇒ **解码 FP×16 未修是此前两个流水线的真缺陷，已修**）
2. **交付话术建议**：以「**micro 反超 +2.59 pp、T3 虚警 −77%、50 FPS**」为主线，
   主动披露 nano 档 −3.12 pp（8px）/ −9.33 pp（4px 严格档）及其**换算成本**（36 ms / 2.87×）。
3. **三套参照系**（话术可选，数值见 §2.1）：
   - vs 冻结 P1 基线：**−3.12 pp nano**（速度 −65%）
   - vs 在位 incumbent（cs_t0043）：**+1.68 pp nano**（即**微小目标召回不降**，速度 −65%）
   - vs 同语义老轮臂（RC2）：−0.12 pp nano（速度 −80.7%）
4. **风险清单**：
   - nano（≤4px）档在 4px 严格匹配下落后 P1 **9.33 pp** ⇒ 若验收方专门打 2×2 点源，需准备补强方案（路线二 P2 家族，见 §6）。
   - **T1 快筛只能排雷、不能选型**（trial_9305 曾出现 T1 全场最高 0.887374 却官方门禁全灭的��例）。
   - **GMC / no-GMC 必须分列报告**，任何混用都会导致结论不可复现。

## 6. 后续（不改变本定案）

- **路线二（P1/P2 + 通道瘦身）已完成并收口**（2026-11-10 全天，详见 memory §113~§126）：
  - **速度目标可达**：真 2px（P1 全路径 320 头）也能进 30 ms —— `p1_hc32 + 颈收窄0.5` = **28.714 ms**（整帧 29.954）；
    `p1_late`（P1 细节参与融合、160 算/320 输出）= 21.2~22.6 ms；P2 系 17.9~21.0 ms。
    **已排除**：P0 highway（+17.13 ms）、dw_head（DW 在 NPU 上是算力反模式）。
  - **但召回目标在同预算内达不到**：P1/P2 家族最优臂 nano **0.6493**（比交付件低 1.73 pp），
    官方 **T2 虚警 FP 118（红线 36）直接判死**，且更慢（22.663 vs 19.629 ms）⇒ **不能替代交付件**。
    - 加通道也不行：`p1_late **hc64**`（真权重，25.425 ms，可正常上板）**nano 0.6047** ⇒ **头更宽反而更差**。
  - **真正的杠杆是配方不是结构**：起点权重（RC2→冻结基线：+1.64 pp 且趋势反转）、周期长度
    （10 轮全退火 vs 50 轮 ep25：**+10.3 pp**）、头继承需「输入尺度匹配」；混训比例被否证。
  - ⇒ **「保留 P1/P2 才能保住微小目标」这一前提不成立**：交付件在 4~8px 档**反超** P1 基线 +2.59 pp，
    只在 ≤4px 档落后 3.12 pp，而那 3 pp 用 P1/P2 在同预算内**换不回来**（更慢 + T2 虚警）。
