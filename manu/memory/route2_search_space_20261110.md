# 路线二搜索空间设计（RK3588：int8 ≤30 ms 且微小目标召回不降）

> 版本：2026-11-10　基线起点：冻结基线 trial_0474 / RC2(trial_0080)
> 交付参照：`trial_0031`（P3 路线，int8 **19.306 ms**，nano 0.6666 / micro 0.8370 / F1 0.887122）
> 目标靶子：nano **≥ 0.6978**（P1 冻结基线水平）；速度预算 **≤30 ms**（硬门槛）

---

## 0. 设计原则：**速度与召回分开定价，再做组合**

早期把「P1/P2 高分辨率」当唯一杠杆，方向错。实测给出三条独立结论：

| 结论 | 证据 | 含义 |
|:--|:--|:--|
| **① 结构只决定速度，不决定召回** | 同配方下 P1(55.5ms)/P2(18~21ms)/P3(19.3ms) 的 nano 差 < 3 pp；而**同结构**换起点权重 nano 差 **+1.64 pp** 且趋势相反 | 召回是**起点+配方**问题，不是结构问题 |
| **② 训练越久，nano 越掉** | 9603：ep3 nano 0.6281 → ep9 **0.5971**（F1 走平、Precision 反升、4px 严格档同步掉 ⇒ 非阈值假象） | 长周期高峰 LR 会**磨掉**微小目标能力 |
| **③ 冻结基线是「UAV 单域 + 3 轮全退火」** | P0 NAS 研究配方：epochs 3 / lr0 7.18e-4 / focal 2.70 / ow 0.55 / **UAV 单域** | 召回的标杆配方是**短周期 + 完整退火 + UAV 主导** |

⇒ **搜索空间 = 结构轴（速度）× 起点轴（召回）× 配方轴（召回）**，三者独立可控、可组合。

**结构轴的三个硬约束（已排除项，不再浪费机时）**：
1. **P0 highway 排除**：+17.13 ms / +62 MB 读写；且只在真 2px（320 特征）结构下形状兼容 ⇒ 28.714+17.13 ≈ 46 ms。
2. **dw_head 排除**：DW 在 NPU 上是算力反模式（每组 1 通道、MAC 阵列空转）⇒ MAC 降幅不转成时延降幅；导出侧已 `if False` 停用。
3. **颈宽 `p2_out_scale` 是唯一有效的省时旋钮**（P1-hc32：32.793 → 28.717，省 4.08 ms），但它同时让颈的两个 conv 需要重训 ⇒ **省时与起点质量冲突**。

## 3. 配方轴：三个独立杠杆（2×2 因子设计中）

| 杠杆 | 取值 | 机理 | 状态 |
|:--|:--|:--|:--|
| **混训比例** | w2.0（P(UAV)=0.667）/ **w8.0（P(UAV)=0.889）** | 冻结基线是 UAV 单域 ⇒ LQ 混训**稀释微小目标分布** | 2×2 因子在跑 |
| **调度** | 50 轮（高峰 LR 久泡）/ **10 轮（cosine 跑满退火）** | 短周期+完整退火＝冻结基线的「收敛即停」 | 2×2 因子在跑 |
| 增广/损失 | mosaic 0.15 / scale 0.10 / translate 0.05 / focal 2.75 / ow 0.40 / wd 2.69e-4 | 与冻结基线比：**mosaic 略重、ow/wd 偏大、LR 偏低** ⇒ 嫌疑次要 | 未单独隔离 |

**训练固定项**：`act=relu`（用户口径：NPU 效率最高，板卡实测比 silu 快 ~1.5×）｜`--head-init merge`（**否证 merge_abs**：abs 抹掉滤波器符号结构，loss 5e3）｜
`--unfreeze-b0b4 1`（all-relu 必须解冻底模早期层）｜`--train-on-native-grid 1 --min-radius 0`（监督落到头的原生 160 网格，单格点目标也算正样本）｜
lr_scale 3.5 / warmup 1.5 / batch 32 / imgsz 640 / 50 或 10 轮。

## 4. 评测口径（严禁混用）

| 口径 | 用途 | 工具 |
|:--|:--|:--|
| **官方三轨门禁**（GMC） | **权威选型**：T1 UAV / T2 龙泉山黄金池 / T3 blind | `manu/training/auto_epoch_gate_check.py` |
| **NanoBench-T1（no-GMC）** | 微小目标分层：nano/micro/small/regular + F1 | `manu/evaluation/tiny_target_subset.py` |
| **T2 孤立微小假峰 FP 台**（no-GMC） | 定位「孤立微小假峰」规模（relu 虚警风险监控） | `manu/evaluation/t2_isolated_tiny_fp.py` |
| **联合门禁** | 速度 × nano 一条命令出判定 | `manu/evaluation/dual_constraint_gate.py` |

- 匹配：**中心欧氏距离 8px 主档 / 4px 严格档**；T2/T3 用 **point-in-bbox**；**不用 IoU**（2×2 目标 IoU 恒≈0）。
- 尺寸分层：**物理像素**（源 640×512 ⇒ 高度 ×0.8 还原），**禁用各向同性 ×640**。
- **GMC 与 no-GMC 分列报告**，任何混用即结论不可复现。

---

## 5. 选臂判据（`route2_acceptance.py`）

⚠️ **不能只按 F1 选 epoch**（晚期 F1 走平而 nano 持续下滑 ⇒ 纯 F1 会挑到 nano 最差的晚期）。
⇒ 规则：**先取「nano ≥ 下限」的 epoch 集合，其中 F1 最高者**；若无 ⇒ 取 nano 最高者并标记 `max_nano_nofloor`。
⇒ 输出同时给 `nano_peak_epoch / nano_peak / select_rule`，轨迹可审计。
