### 2. 核心判决（直接回答"极限之问"）
1. **F1=0.92 不是信息论极限**：当前前端管线的诚实工程上界为 **F1=0.9570**（ΔF1=+0.036），纯数学上界 0.9647；
2. **FN 的 70/30 分裂（最关键结构性发现）**：
   - **前端死区 1,714（70%）**：conf>=0.02 候选池中完全无点的真值，任何后处理无解，只能靠输入管道 v2（Phase-B，Twin A/B）解锁；
   - **候选池内丢失 743（30%）**：后处理可捞的理论上限；
3. **算法性虚警 ~1,045 处可压**（1,472 − 389 飞鸟 − 24 标注漂移 ≈ 1,059）；
4. **Top-k=100 饱和帧数为 0**：候选缓存无截断隐患。

## 二、Phase-A 后处理攻坚系统（已实现，2026-09-16）

### 1. 四大模块设计（全部默认关闭，零漂移继承 legacy SOTA）
在 `manu/eval_bidirectional_track_fusion.py`（SOTA 主评测脚本）内扩展：
1. **航迹门控深潜打捞（P1）**：`th_deep_salvage`（0.035~0.05）+ `min_hits_deep_salvage`；仅存活 >= min_hits 的成熟航迹可在空域深潜区关联弱脉冲，严禁自发生成新航迹；深潜候选同样经过密集杂波簇过滤（cluster_radius=25/max_neighbors=2）；
2. **弹性长缝合（P2）**：`stitch_long_gap`（8~16 帧）+ `stitch_max_vel_diff`（默认 4.0 px/f）；扩展间隙必须通过端点速度相干性检验（走停：两端均近零速；巡航：速度矢量一致），空间门外推距离 `max(25, 10×gap)`；
3. **悬停动力学锁止（P3）**：
   - 准静态内插：`hover_vel_thresh`（表观速度 <= 阈值的间隙，线性内插物理精确）+ `hover_infill_gap`（10~15 帧）；
   - 尾部惯性 Coasting：`coast_max_frames`（10~20 帧）+ 阻尼外推（damping=0.85）；
   - **`hover_sky_only=1`（默认强制空域）**：地表静止航迹是坏点/杂波领域，严禁复活（实测关闭该门控 FP +582 → 开启 +445，仍需更紧参数）；
   - 合成点（内插/Coasting）带 6px 同帧去重，避免同一真值被重复计数（1 TP + 1 FP）；
4. **尺度门控双专家（P4）**：`--bbox-cache` 挂载 YOLO26 Bbox 专家缓存（`manu/cache_yolo26_bbox_inferences.py` 生成，默认权重 `runs/optuna_uav_recall_sgpu/trial_0028/weights/best.pt`）；`min(w,h) >= size_gate`（默认 40px）且 conf 达标的框中心注入点流（与热图候选去重半径 20px），大机身建筑重叠目标（HC5-B）由 Bbox 范式原生捕获；
5. **空域感知刚性剪枝**：`min_rigid_disp_sky` 允许天空区采用更宽松的坏点剪枝阈值（0=完全豁免），保护出生即悬停的真实目标。

### 2. 零漂移验证（铁律级）
- 本地合成冒烟测试 5 项全过（悬停锁止 30→40 TP、天空剪枝豁免 19→29、深潜 5→11、双专家 0→10、legacy 零漂移）；
- **真实缓存全盘 legacy 复现：TP=22,654 / FP=1,434 / F1=0.9209 与 SOTA 标称逐位一致**（bbox 口径，labels 富化后）；
- 单次全盘评测仅 ~4.4 秒（CPU），网格调参成本极低。

### 5. Phase-A 全盘坐标上升终局（2026-09-16）
服务器执行：`manu/tune_phase_a_fusion.py --cache-file runs/gmc_eval/uav_median_trial0474_cache.pkl --bbox-cache runs/gmc_eval/uav_median_bbox_trial0028_cache.pkl`。

本次调参输出的 Legacy 为 **Strict Distance** 口径（TP=22,616/FP=1,472/F1=0.9194），不是已交付的 In-BBox 口径 SOTA（TP=22,654/FP=1,434/F1=0.9209）。因此本次结果内部可以比较，但不得与 0.9209 直接混口径比较。

| 配置 | F1 | Recall | Precision | TP | FP | 相对 Legacy |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Legacy 基线 | 0.9194 | 90.06% | 93.89% | 22,616 | 1,472 | — |
| 深潜最优 `deep=0.035/hits=4` | **0.9204** | **90.65%** | **93.48%** | **22,762** | **1,588** | F1 +0.0010 / TP +146 / FP +116 |
| 悬停代表档 `0.60/10/10/sky1` | 0.9165 | 90.83% | 92.49% | 22,808 | 1,852 | F1 -0.0029 / TP +192 / FP +380 |

关键判决：
- Phase-A 最优仅通过 **Recall +0.59pp** 换取 **Precision -0.41pp**，新增检测的边际精度为 `146/(146+116)=55.7%`，不是 Recall 与 Precision 同时提升；
- 全部五个 Stage 完成后，最佳配置仍只有 `deep=0.035/hits=4`，长缝合、悬停锁止、天空剪枝和双专家没有带来可交付的额外增益；
- `F1 +0.0010` 属于边际收益，不构成实质 SOTA 突破，且低于已交付的 bbox 口径 F1=0.9209（仅作指标提醒，不能混合口径比较）；
- 双专家 Stage 5 的 6 组参数结果完全相同，说明当前全盘评测中未产生有效增量，后续若重启该方向必须先按难例逐序列核查注入链路；
- Phase-A 后处理路线正式判定为**收益饱和/不再投入主算力**。Oracle-B 的 F1=0.9570 只能作为固定前端候选池上的理想上界，不能解释为 Phase-A 可达目标。

## 三、后续路线
1. Oracle 的 0.9570 继续保留为 **Strict Distance + Trial 0474 候选池** 条件上界；若需要与 bbox 交付指标比较，必须重新运行修正版 Oracle 的 `--match-mode bbox`，禁止混用；
2. Phase-A 仅保留 `deep=0.035/hits=4` 作为实验参考档，不再以 F1>=0.925 为后处理目标；
3. 后续主线转入 Phase-B：输入管道 v2（双窗口运动补偿中值 / 视差感知对齐）Twin A/B 冷启动对照，优先攻克 1,714 个前端死区；
4. 任何新后处理方案必须同时报告 TP、FP、Recall、Precision 与边际新增检测精度，避免只看 F1 造成“以精度换召回”的假突破。
