## §301（2026-11-23 13:40~14:10）· 🔴🔴 **训练轴的「种子噪声」比效应本身大一个量级**（同配方换 seed：nano 跨度中位 **130 阶** / t1 **1181 阶**）＋ 🟢 由此确立的搜索方法论：**单臂读数不可信 ⇒ 关键区必须多种子复现 + 用中位数判定** ＋ 🟢 新最高优先级实验：**以基线本体为 init 的自锚微调**（F1↔nano4 兑换率实测 ≥1.55 阶 ⇒ 要赢必须 <1）

### 一、🔴🔴 实测：同配方、只换 seed，指标跨度极大（全库 187 个复现组 / 4348 个臂）

🔴 **推论（本轮最重要的方法论结论）**：
① **单臂读数不可信** —— 我们要打的是 **1 阶**的严格优，而单臂噪声是 **±65 阶（nano）/ ±590 阶（t1）** 量级 ⇒
**任何「某臂 +13 阶 nano」的说法，在没有复现之前一律按噪声处理**；
② 因此**严格优的成立判据必须是「同配方家族的中位数过线」**（既有升轨规则「家族 n ≥ 4」正好对应 ⇒ 不要改）；
③ **搜索预算的用法要分两层**：
**广度层**（找「哪些配方有大幅效应」）用单 seed（PT3 的 3994 臂就干这个 —— 它是**响应面测绘**，不是判决）；
**判决层**（证明「这个配方真的赢」）必须在**关键区多种子复现**（SD 轴 band A/B/C 改为 **同配方 2~3 个 seed**、用中位数）。

### 二、🟢 F1 ↔ nano4 的兑换率实测（以基线本体为 init 的 61 个臂）⇒ 要赢必须把比率压到 <1

全库已有 **61 个臂以基线 `1990055@5` 为 init**（臂号段 `2100000~2100029`，PT1「T1 供体抛光轴」），

🔴 **结论**：**最省的比率 ≈ 1.55 阶 F1 换 1 阶 nano4**，**恒 > 1** ⇒ **照这批配方永远赢不了**（严格门禁要求 F1 也 ≥ 基线）。
🔴 **为什么还值得试**：`1990055` 是**唯一**「六轴同时在顶点」的 init（其余 init 至少有一轴已经欠账）

`lr` 只有 **0.15~0.35** ⇒ **「小 lr × 强自锚（anchor_ckpt = init 本身）」这个组合从未被测过**
（`anchor_l2` 在 1246 个训练臂里 `≥0.005` **零样本**）⇒ **这是当前最高优先级的空白**。

```bash
cd /tmp/an   # 本地只读快照
python3 - <<'PY'
import json, collections, statistics
d=json.load(open('snap_ledger.json')); arms=d.get('arms',{})
B={'nano':0.7242438563327032,'nano4':0.6609168241965974,'f1':0.8906832039622916,'t1':0.8909238824339264,'t3':0.9488855869242199}
Q={'nano':2.3629489603e-4,'nano4':2.3629489603e-4,'f1':1.8536e-5,'t1':4.5518e-6,'t3':5.206e-5}
def val(v,a):
    s=v.get('picked') or {}; o=v.get('official') or {}
    x=s.get(a) if a in ('nano','nano4','f1') else o.get(a)

def sig(v):
    p=v.get('params') or {}
    if not p.get('init'): return None
    k=('init','lr','lr_floor','sw','swl','swb','thr','maxside','cp_prob','anchor_l2','epochs','mix','fb','ow','wd','mosaic','scale','translate','clip','backbone_lr','sched','warmup','head_src','uf','mr','native_grid')
```
