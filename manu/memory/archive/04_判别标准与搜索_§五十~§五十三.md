## 1. 决策一句话

    **全部落在 RC1 自身 epoch 间包络内** ⇒ **「复现失败」是判据错觉，不是管线有未发现的差异**。
- ⇒ 追加两个**可判定**的对照 trial（把"复现"从争论变成实验）：**#12 natural 复现对照**、**#13 w4.0 目标比例对照**。

## 2. 5-epoch 协议：为什么值得改，以及**必须同时换擂主**

- **收益（实测数据支撑）**：RC1 自己 5-epoch 曲线显示 **Ep5 的 U = +0.026260 < Ep3 的 +0.027579**
  （Ep5：T1 F1 0.900501/FP 1023，T2 0.998949/33，T3 0.874924/502）
  ⇒ **跑满 5 epoch 源域退化更大**（ΔF1_T1 = −0.005235，**已跌破严格红线 −0.005**，只过受控放宽通道）
  ⇒ **"提高 LQ 比例能否护住源域"这个搜索假设在 5 epoch 下被放大** ⇒ 测量区间更贴近最终交付的 5-epoch 模型。
- ⚠️ **代价（必须记账）**：
  - **擂主从 RC1/Ep3（U=0.027579）变成 RC1/Ep5（U=0.026260）** ⇒ 跨尺度比较是错的；
  - 单 trial 从 ~47 min 变 ~65 min（训练 5 ep ≈ 45.5 min + 门禁 19 min）⇒ 20h 预算从 ~102 trial 降到 **~65 trial**；
  - RC1 自己的 Ep5 **打不过自己的 Ep3** ⇒ "5-epoch 模型打败 RC1/Ep3"是**更难**的目标，但也是**更真实**的目标。
- **结论（我的技术判断）**：值得改，但**必须在报告里同时给出"vs RC1/Ep5（同口径）"和"vs RC1/Ep3（用户目标）"两个结论**。

## 4. ⭐ 复现判据工具 `reproduction_check()`（`mix_ratio_judgement.py`）

**这是用户那句"相同配置无法复现 rc1 的精度，这个不正常吧？"的正式落地产物。**

- `RC1_EPOCH_CURVE`：RC1 的**完整 6 点曲线**（epoch 0~5，源自 `RC1.json → full_cycle_curve`）。
- `rc1_epoch_band()`：RC1 **自身**在 epoch 1~5 上的逐指标 min/max 包络
  （实测 **T3 F1 0.8469~0.8749（跨度 0.028）**、**T1 FP 941~1232（跨度 291）**、T2 FP 31~35）。
- `reproduction_check(cand, epoch)` 三级判决：
  - **`EXACT_REPRO`** —— 与 RC1[epoch] 逐项差都在容差内（T1/T3 F1 ±2~3e-3、FP ±30~40、T2 F1 ±1e-3、FP ±4）
    ⇒ 位级复现：数据流完全一致时**应当**成立，只剩 GPU 非确定性；
  - **`BAND_REPRO`** —— 不满足逐项容差，但**落在 RC1 自身 epoch 间包络内** ⇒ 正常波动，**不能据此说复现失败**；
  - **`NOT_REPRO`** —— 连包络都出不去 ⇒ 才是真异常。
- 🔥 **已产出的关键实证**：用该工具回测 **trial_0000（旧调度口径，natural + RC1 原值超参）** ⇒
  **`NOT_REPRO`**，出包络项 = **track1_f1（0.902455 > 上界 0.902215）与 track2_fp（37 > 上界 35）**
  ⇒ **旧 cosine 周期确实训出了系统性不同的模型（源域更差、虚警更多），不只是随机噪声**
  ⇒ **反过来正面印证了 §四十九 6.8 的 cosine 周期诊断**（不是"随机性为主因"）。
  同时 `reproduction_check(EP[5], 3)` = **`BAND_REPRO`** ⇒ 同一 run 内跨 epoch 的差异属正常。

- ⚠️ **必须同时记住的代价**（§五十二 实测）：**U 最高的那批（trial_0061 +0.057861、0066 +0.053071、0058 +0.051694…）
  恰恰是靠"源域退让"换来的**（T1 F1 0.8962~0.8989，比 RC1 低 0.003~0.006；T1 FP 1046~1217，比 RC1 高 105~276）
  ⇒ 它们只过**放宽通道**。
  而**严格过线的最优 trial_0080（T1 F1 0.901910 ≈ RC1 0.901918，源域零退让）**才是"回放缓冲垫"叙事的正确落点。
  ⇒ **回放比例的甜点与一级红线的最优点是同一个**，这是本轮最有价值的结构性结论。

### 3.3 严格代码与度量门禁
- 一票否决制 + 三级效用函数（Utility）让自动搜索当"冷酷质检员"：
  任何以牺牲大盘为代价的"伪提点"被自动剪枝，新模型**必须在帕累托意义上真正更强**才能上位。
- **实现现状**：`manu/training/mix_ratio_judgement.py`
  （一级双通道红线 → 二级帕累托占优 → 三级同基准 U 裁决；**绝不用加权求和**）。
  本轮实测：**47/76 打败 RC1，但只有 7 个同时严格过线** ⇒ 门禁确实把"伪提点"挡掉了 40/76。

## 6. 下一场景落地清单（沙漠 / 海面 / 低空密林）

1. **人工定界（30 分钟）**：剔硬件非均匀性条纹 + 非防空视角 → Ignore 免责集；挑 1 条典型死穴 → Blind 难例；其余 → Train/Anchor。
2. **特征基底固化**：自动生成 GMC 官方语义通道 + **sha256 完整性自检** ⇒ 保证零协变量偏移（同一特征基底可直接跨场景复用）。
3. **动力学调优**：以 RC2 为擂主，**先验空间锁 w2.0~w2.5 + lr_scale 2.0~2.8**（不必从零搜），
   只放开"新场景配比"这一个自由度 ⇒ 搜索维度骤降，算力省在刀刃上。
4. **门禁裁决**：三级漏斗自动跑；**"新域真突破 + 源域绝对不退化"** 同时满足才交权杖。
5. **回放底座沉淀**：把新场景高质量切片按配额入大盘 ⇒ 下一轮飞轮的存量更大、缓冲垫更厚。
