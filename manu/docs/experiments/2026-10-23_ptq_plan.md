# 2026-10-23 PTQ 实验计划（纯 PTQ，不碰 QAT）

> 目标：最大化 RK3588 上 trial_0080 热图模型的 int8 精度，评测集 = 三个核心 val（T1 Anti-UAV / T2 黄金池 / T3 001324 盲测）。
> **硬约束**：输入张量必须保持 INT8（`rknn_inputs_set` 0.34 ms；FP16 输入 = 45.41 ms，25 fps 预算爆掉）。
> **口径**：同帧 / 同解码器 / 同 GT / 同阈值 / topk=100；量化损失 = F1(PT float) − F1(int8 臂)，逐轨给。

### 1.3 由此得到的轴判决

| 轴 | 判决 | 依据 |
|:--|:--|:--|
| `optimization_level` 0/1/2/3 | ❌ **完全无效**（已证伪） | olv0/olv2 与 base 的 cos/mse **逐位相同**（0.973092 / 3.566e-06） |
| `enable_flash_attention` | ❌ **完全无效**（已证伪） | fa 与 base 逐位相同；该图无 SDPA 融合差异 |
| `quantized_method` channel vs layer | ✅ **channel 更优**（保留） | layer 的 cos 更低、mse 更高（4.04e-06 vs 3.57e-06） |
| `quantized_method=group{SIZE}` | ❌ **平台死路** | `only support when quantized_dtype = 'w4a16'`；rk3588 只支持 w8a8 |
| `quantized_dtype=w8a16` | ❌ **平台死路** | `not support in 'rk3588'` |
| `quantized_algorithm=gdq` | ❌ **平台死路** | `only support in ['w4a16','w8a16']` |
| `quantized_algorithm=kl_divergence` | ❌ **四个校准集全 F1=0** | 输出量程削顶（上限 0.2399 < th 0.30） |
| `quantized_algorithm=normal` | ✅ **当前唯一可用** | — |
| `quantized_algorithm=mmse` | ⏳ **未完成**（29 min → 6/151 层，ETA 8~11 h） | 见 §4 决策 |
| **校准集** | ✅ **真实有效轴**（未充分利用） | set_1 的 mse 1.67e-06 vs Set-A 的 3.57e-06（**好 2.1×**）；但 set_3 的 F1 0.78 最高 ⇒ 不同校准集在不同指标上领先 |
| `quantized_hybrid_level=1` | ⚠️ **激活精度最优但输入 dtype 存疑** | cos 0.9895 / mse 1.08e-06（**最好，比 base 好 3.3×**）；**必须在板端确认 InputOperator 是否 INT8** |

### 1.4 一个必须记住的方法论陷阱

**`cos_hm` 更高 ≠ `F1` 更高**（100 帧小样本）：
- `screen_layer`：cos 0.9679（最低）但 F1 0.7512（第二高）
- `screen_v2/set_3`：cos 0.9734 但 F1 0.7800（最高）
- `screen_hyb1_diag`：cos 0.9895（最高）但 F1 0.7299（与 base 完全相同）

⇒ **100 帧 F1 的抽样噪声 ≥ 0.05，cos/mse 才是稳定排序指标，F1 只能用于最终验证。**
⇒ 选型必须用**大样本**（≥2000 帧/轨）或用 cos+mse 排序后再验证。

## 3. 评测口径（铁律）

1. **PC 模拟器做筛选，板卡只做最终验收**（板卡 ctx 上限 2；全量 60,610 帧板端 ~5.8 h）。
2. **同帧同解码器同 GT 同阈值 topk=100**；量化损失 = F1(PT float) − F1(臂)，**逐轨给**，禁止写成全局规律。
3. **GT 根**：T1 = `uav_gmc_median/labels/val`（命名 `{seq}__{%06d}.txt`）；T2/T3 = 各自目录。**严禁**用龙泉山标签树。
4. **阈值重标定逐轨**（已知位移 0 / −0.10 / +0.05），报告必须同时给 th=0.30 同口径值与最优阈值值。
5. **验收闸门**：候选模型的 `InputOperator` dtype 必须为 INT8（从板端日志 `input attr` / 构建日志 operator 表读），否则不予交付。
6. 板卡 ctx 计数用 `ps -eo comm | grep -c '^rknn_heatmap'`（**不用 `ps -eo args`**，会把 ssh/bash 包装一起数）。
