# 心路历程

1. 拿到任务，先对公司现有的数据进行了整理和分析，发现公司数据多样性不足，作为算法设计的基础不是很合适。
2. 了解领域相关进展，看了一些综述的文章，发现目前领域的研究热点是红外模态。
3. 下载了几个学术界常用的“anti-uav”红外数据集，发现这些数据多样性还可以，极端目标非常多，很适合作为算法开发的初版数据集。
4. 首先尝试比较新的“yolo26”框架，使用常规手段做“baseline model”。
5. 尝试编码序列信息，增强模型性能。
6. p2 head.
7. 超参搜索。
8. 各种长时序列特征实验。
9. 增加监督信息（同时预测多帧位置和运动矢量）。
10. heatmap based.
11. 增加跟踪器，运动约束。
12. unet based.
13. corr
14. imgsz 960 / 1280
