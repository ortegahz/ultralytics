### P03 · 立靶：为什么 1~3 px 是「表征问题」，不是「小目标问题」

| 项 | 内容 |
|:--|:--|
| **Layout** | B · 左右双栏（冷 / 暖色对立） |
| **主张** | 目标不是「有轮廓的小目标」，是「局部的 PSF 冲激」⇒ 表征必须换 |
| **时长** | 1.5 min |

**元素**

- **眉标**：`第一幕 · 把问题定义对`
- **标题**：`1~3 像素：没有轮廓，只有一个冲激`
- **左栏（冷色 `#E9EFF5`）｜物理难点**：
  - `1~3 px` 目标，无稳定纹理 / 部件 / 边缘
  - 响应可能**低于同帧全图噪声极值**
  - 相机运动把静态地物变成结构性差分边缘（伪目标主要来源）
  - 瞬态暗化 / 闪烁 / 翻滚 / 悬停
  - 坏点 / 地表热斑 / 云层纹理 / 飞鸟与无人机响应同构
- **右栏（暖色 `#F7EFE9`）｜三重硬约束**：
  - **精度**：单帧官方域 F1 必须过线（起点 0.6565）
  - **速度**：板端 int8 ≤ 20 ms，e2e 实时
  - **交付**：嵌入式组要能直接 `.so` 集成，不许有我方 NFS 路径
