### 1.1 本项目现状：单帧判别在物理上注定失败

`manu/memory/hard_cases.md:23-27` 已确立的硬事实：

- 全盘刚性坏点剪枝后剩余 1 472 处虚警，其中 **389 处（26.4%）**集中在两条序列：
  - `01_4485_1167-2666`：**212 FP**，其中 200 帧属持续飞行轨迹。人工逐帧回溯确认为**空中飞鸟长时间滑翔**，焦平面仅占 1~2 px，退化为点冲激高斯斑（PSF），**滑翔阶段轨迹平滑、匀速，与远距固定翼/四旋翼无人机完全同构不可区分**。
  - `wg2022_ir_020_split_07`：**226 FP**，其中 189 帧属持续飞行轨迹。确认为飞鸟，**仅在偶发扑翼（Flapping）瞬间**露出红外辐射周期性闪烁与侧向微抖动破绽。
- 当前处理是**战略搁置**（整条序列排除）：`manu/diagnostics/audit_substandard_cases.py:198-201` 的 `AVIAN_SEQUENCES = {"01_4485_1167-2666", "wg2022_ir_020_split_07"}` + `--exclude-avian` 直接跳过整条序列。剔除后系统真实 Precision 达 **95.4%**。

这直接决定了本次调研的边界：**不可能靠单帧让检测器学会「拒绝疑似飞鸟的亮斑」**——远距无人机的召回会断崖式下跌。行业通行做法与本项目结论一致：**绝不牺牲前端检测器召回，把鸟机判别做成挂在跟踪器后端的轻量级航迹过滤器**。

## 2. 论文要点提炼

### 2.1 方法骨架

原文 §1 末段 + 图 1：

```
红外视频序列
   └─ 预处理：Harris 角点匹配 → 相机运动补偿 → 目标检测与连续跟踪
        ├─ 路线①  面积时序特征：线性拟合 → 残差 → 傅里叶变换 → s_A ∈ [0,1]
        └─ 路线②  轮廓形态特征：小孔成像模型 → 相对三维轨迹 → 姿态标签
                                  → 姿态自适应轮廓提取 → s_C ∈ [0,1]
   └─ D-S 证据融合（按可信度折扣 BPA → 组合 → Bel 比较 → τ 判决）
```

物理依据（原文 §2.1）：无人机是**刚性**人造结构，机架/外壳/旋翼支架无柔性形变，飞行中整体轮廓恒定，面积变化仅由飞行距离、俯仰偏航宏观姿态、镜头视距决定 ⇒ 连续帧间面积变化**连续、平缓、波动幅度小**；飞鸟是**柔性**生物结构，骨骼、羽翼、躯干可收缩舒展 ⇒ 面积**波动幅度大、占自身面积比例高、波动更频繁**。

### 2.2 第一重特征：面积时序变化（★ 重点借鉴）

**符号约定**：`a_i` = 第 i 帧目标所占面积（像素），`T` = 跟踪长度。

**① 线性拟合（式 1、2）** —— 最小二乘：

$$k=\frac{T\sum_{i=1}^{T} i a_i-\left(\sum_{i=1}^{T} i\right)\left(\sum_{i=1}^{T} a_i\right)}{T\sum_{i=1}^{T} i^{2}-\left(\sum_{i=1}^{T} i\right)^{2}},\qquad b=\frac{\sum_{i=1}^{T} a_i-k\sum_{i=1}^{T} i}{T}$$

**② 残差（§2.1 第 2 步）**：

$$\delta_i = a_i - \hat a_i ,\qquad R=\{\delta_1,\delta_2,\cdots,\delta_T\}$$

`R` 反映面积变化中的**波动**成分（已剔除整体趋势——距离变化/尺度增长）。

**③ 频域量化（式 3）** —— 对残差序列做 DFT：

$$F(\delta)=\sqrt{\frac{1}{T}}\sum_{i=1}^{T}\delta_i\,e^{-j2\pi(i-1)f/T}$$

**④ 单维得分 `s_A`**：把**残差波动幅值**与**傅里叶高频能量**在参数调优子集上做 **min-max 归一化后等权融合** ⇒ `s_A ∈ [0,1]`，**越趋近 1 越符合飞鸟的面积波动特性**。

**⑤ 物理验证（原文图 2）**：无人机常规工况下面积波动幅度较小、**波动占目标自身面积的比例低**；飞鸟波动幅度大、比例高、出现更频繁。

**⑥ 时间开销（原文 §3.5）**：**「所提算法仅需累积 5~12 帧序列信息即可完成初步判别」**，原因是鸟类振翅运动天然具备 5~12 帧的轮廓周期。

### 2.4 D-S 证据融合与判决

**原始 BPA（§2.3）**：

$$m_A(\{\text{Bird}\})=r_A s_A,\quad m_A(\{\text{UAV}\})=r_A(1-s_A),\quad m_A(\Theta)=1-r_A$$

（`m_C` 同构）

**证据折扣（§2.3.1）** —— 这是全文最值得抄的设计思想：

- 面积时序特征可信度：**固定常数 `r_A = 0.85`**。原文理由：「面积时序特征基于多帧时序统计提取波动信息，**对远距离小像素目标鲁棒性强，受目标成像像素规模影响微弱**」。
- 轮廓形态特征可信度（式 20）：

$$r_C=\frac{1}{1+\exp\!\left(-\frac{a_t-a_{\text{mid}}}{\sigma}\right)},\qquad a_{\text{mid}}=460\ \text{pixels},\ \sigma=140$$

  原文：「当目标为**远距离小像素目标**，`a_t` 数值小，`r_C` 趋近于 0，轮廓证据可信度低；当目标成像充足、轮廓完整，`r_C` 趋近于 1。」

**融合输出（式 23）**：`m({Bird})`、`m({UAV})`、`m(Θ)`（全局不确定度，不直接输出类别）。

**判决（式 24、25）**：

$$\text{Bel}(\text{Bird})=m(\{\text{Bird}\}),\qquad \text{Bel}(\text{UAV})=m(\{\text{UAV}\})$$

$$\text{Result}=\begin{cases}\text{Bird}, & \text{Bel}(\text{Bird})\ge \text{Bel}(\text{UAV})\\ \text{UAV}, & \text{Bel}(\text{UAV})>\text{Bel}(\text{Bird})\end{cases}$$

判决置信阈值 **τ = 0.48**（在参数调优子集上标定）。原文明确「本文实际二分类应用中不设置悬置不可判定类别，所有样本均输出飞鸟或者无人机」。

**§3.6 泛化补充实验**：

- **§3.6.1 昆虫**：远距离蚊虫/飞蛾成像太低无法检出或被当作噪点；**近距离大型昆虫（蜻蜓、蜜蜂）因振翅幅度大、面积时序特征贴近小型鸟类，存在被误判为飞鸟的可能**。原文判断：「此类错误仅属于『昆虫→鸟类』的正向虚警，**不会出现将干扰目标误判为无人机的关键错误，不会干扰系统对可疑无人机的告警判定**，工程应用层面可接受。」
- **§3.6.2 扑翼型无人机**（18 段互联网公开可见光，仿真热成像）：**仅 8 段识别正确**，其余被误判为飞鸟。原文分析：识别正确的 8 段中「机翼区域等效热源水平极低，机翼部分无法形成有效目标轮廓，仅机身躯干呈现显著可识别特征」；反之「若无人机机翼区域表现出显著等效热源、机翼轮廓完整显现时，扑翼无人机将表现出与鸟类类似的周期性形态波动特征，此时本文算法易将其误判为飞鸟」。

**§4 结论中对我们最有价值的一句**（§3.4.2 末尾 + §4 呼应）：

> 「……（微）小目标截面、长时航迹运动特征与小微型无人机存在显著区分度，可依靠雷达子系统完成前置筛选过滤，弥补纯红外识别的不足。」

## 3. 适配性分析：逐项「可借鉴 / 需改造 / 不可照搬」

| 论文组件 | 本项目可用代理量 | 适配判定 | 依据 |
|:--|:--|:--|:--|
| 面积时序残差 δ_i + 傅里叶高频能量 → `s_A` | 连通域 `area`、blob 能量 `sum`、热图峰值 `score` | **✅ 可直接借鉴（需换代理量）** | 消融中单特征最强且对远距模糊目标最友好；不依赖二值掩码/轮廓点集/像素规模阈值 |
| 5~12 帧起判 | 航迹 `hits` / `observations` 长度 | **✅ 可直接借鉴** | 原文明确「仅需累积 5~12 帧」 |
| D-S 证据折扣 + 可信度加权 | `r_A` 固定 + 第二路 `r` 随尺度/轨迹长度衰减 | **🟡 框架可借鉴，公式需改造** | 「按成像质量给证据源打折」的思想可迁移 |
| 运动学特征（悬停/定高/折线 vs 高频起伏） | `x[4]` 的 vx,vy、`start_pos`、`observations` 二阶差分 | **🟡 论文没有，可自加** | 论文引言反而批评这类浅层统计量（「面对短片段残缺航迹时区分效果有限」）⇒ 必须与面积时序**融合**，不可单用 |
| 姿态自适应轮廓形态 `s_C` | —— | **❌ 不可照搬** | 依赖 (a) 干净天空帧差二值掩码 `D_t`；(b) 轮廓点集 `(x_i,y_i)`；(c) 目标像素规模；(d) 相机焦距 F。我们业务域目标 1~2 px PSF ⇒ 前三者全废、`r_C≈0` |
| 相对三维轨迹重建 → 姿态标签 | —— | **❌ 不可照搬** | 同上；且我们无标定焦距参数 |
| 序列级二分类评价口径 | 我们的 track 级输出 | **✅ 可对齐** | §5 |

### 3.1 关于「面积 → 代理量」的替换（关键工程细节）

论文的 `a_i` 是**目标占据的像素面积**。我们的检测头是**中心点热图回归**（无框），`manu/evaluation/heatmap_evaluate.py:16` 的 `extract_peaks` 只返回 `points` + `scores`（3×3 max-pool NMS + 亚像素 offset 解码，`:90-91`、`:116-120`）。

可用的尺寸类信号**已经存在但没进跟踪器**：

| 信号 | 来源 | 说明 |
|:--|:--|:--|
| `area` | `manu/data/multiscale_heatmap_cache.py:14-21` 缓存 schema：`area` int32「component pixel count, the dilation/energy gate input」 | 连通域像素数 |
| `sums` | 同 schema：`sums` float32「component heatmap integral」 | blob 能量（连续量） |
| `sizes` | 同 schema：`sizes` float32 (M,2)「component bounding box w/h in native pixels」 | 连通域 bbox 尺寸 |
| `score` | `extract_peaks` 输出 | 热图峰值 ∈[0,1] |

**但是**：`manu/evaluation/system_sota_longquan.py:240-270` 的 `make_records` 把缓存里的 `sizes`/`area`/`sums` **全部丢弃**，只保留 `pred_points`/`pred_scores` ⇒ **跟踪器输入侧目前没有任何尺寸信号**。

**因此「面积代理量」的选择是本方案的成败关键**：

| 方案 | 代理量 | 评价 |
|:--|:--|:--|
| P1 | `area`（连通域像素数） | ❌ 1~2 px 目标只有 1–2 个灰阶 ⇒ 残差序列是量化阶梯，FFT 高频能量被量化噪声主导 |
| P2 | `sum`（热图积分 / blob 能量） | ✅ 连续量，分辨率远高于像素计数 ⇒ **首选** |
| P3 | `area × peak` 或 `score` 序列 | 🟡 可作补充（幅度强度代理），但 `score` 受阈值/量化影响，需实测 |
| P4 | 11×11 窗口内自适应阈值亮斑像素数 | 🟡 需额外定义阈值规则，跨域不稳定；可作 P2 的交叉验证 |

**建议**：主用 **P2（`sum` 序列）** 做残差-频谱；**P3（`peak` 序列）** 作第二路幅度证据；`area` 仅用于「目标成像质量」的可信度估计（替代论文的 `a_t`）。

### 3.2 关于「运动学特征」的取与舍

论文**没有**用运动学特征，但它的引言（§1）明确批评过这条路线：

> 「上述基于人工航迹特征的识别思路通常利用人为定义的速度、爬升率、轨迹平滑度等浅层运动统计量，**无法自主挖掘航迹中隐含的长时序依赖关系，面对短片段残缺航迹时区分效果有限**。」

→ **这是对我们方案的直接警告**：运动学特征（悬停占比、jerk）必须与面积时序特征**融合**使用，且要在长序列上验证，不能当独立判据。

尽管如此，运动学证据在**物理上是互补的**，且我们已有证据表明它携带信息：

- `manu/diagnostics/diagnose_substandard_pathology.py:171-181` 已经实现了一套航迹运动学统计：`net_disp`、`pos_var`、`lifetime`；`:216-226` 的分型判据中 **`net_disp >= 8.0 and lifetime >= 8 → persistent_flyer`（= 飞鸟）** ⇒ 说明「持续飞行 + 净位移大」这条粗判据**已经能在现成诊断脚本里抓到一部分飞鸟航迹**，是现成的 baseline 对照。
- `manu/evaluation/eval_bidirectional_track_fusion.py:308-326` 已有 **Step D 死轨迹清除 + 地面静态杂波抑制** 的判据先例（`net_displacement < min_displacement` ⇒ 判为地面建筑/树枝抖动而清除；交付档 `min_disp = 2.5`，`manu/evaluation/system_sota_longquan.py:61`）—— **我们要在同一个位置加 bird filter，是有先例的。**
- 板端已有 `Comp` 结构体 `manu/pipeline/npu/mosaic_core.h:839-846` 含 `tag/cx/cy/w/h/area/peak/sum` ⇒ **尺寸信号在板端也是现成的**；只是 `manu/pipeline/npu/mosaic_pipeline.cpp:2274-2279` 的 `FeedFusion` 只搬了 `x/y/score` 三个字段，`w/h/area/sum` **在进跟踪器前被丢弃** ⇒ 扩一个 `TrackFusionCand` 结构体即可，**零额外算力**。

### 4.3 航迹级打分器（伪码）

```
输入: 一条已起批的 track，观测序列 {(f_i, pos_i, score_i, sum_i, area_i)}
      可信度: 目标成像质量 q = f(area_i 的中位数, sum_i 的中位数, 观测帧数)

# —— 路线 A：面积时序特征（移植论文 §2.1）——
a_i        = sum_i                      # 连续代理量，见 §3.1 的 P2
k, b       = 最小二乘线性拟合(a_i, i)   # 式 1、2
delta_i    = a_i - (k*i + b)             # 残差
w_res      = std(delta) / (mean(a)+eps)  # 残差波动幅值（相对归一化）
E_hf       = Σ_{f > f_cut} |F(delta)|^2 / Σ_f |F(delta)|^2   # 式 3，高频能量占比
s_A_raw    = 0.5*norm(w_res) + 0.5*norm(E_hf)      # 论文式：min-max 归一化后等权融合

# —— 路线 K：运动学特征（自加，非论文内容）——
v_i        = 相邻观测的位移/Δf
jerk_i     = v_i - v_{i-1}
s_K_raw    = 0.5*norm(jerk 的高频占比) + 0.5*norm(速度方向变化率)
#           悬停占比（速度低但位置持续微抖）作为额外的负向证据

# —— D-S 融合（框架移植论文 §2.3）——
r_A = 0.85                        # 固定，照搬论文
r_K = sigmoid((q - q_mid)/sigma_K)  # 仿论文 r_C 的形状：成像/轨迹质量差则证据折价
m_A = {Bird: r_A*s_A, UAV: r_A*(1-s_A), Θ: 1-r_A}
m_K = {Bird: r_K*s_K, UAV: r_K*(1-s_K), Θ: 1-r_K}
Bel = Dempster 组合(m_A, m_K)

输出: bird_score = Bel(Bird)/(Bel(Bird)+Bel(UAV))   # ∈[0,1]，供降权使用
```

**与论文的关键差异（必须写进实现注释）**：

1. 论文是**二值判决**（输出 Bird/UAV），我们是**连续分数**⇒ 论文的 τ=0.48 不能直接照搬，需在 §6 的标定集上重新定（且要**预注册**后再跑评测，见 §5.5）。
2. 论文 `m(Θ)` 保留不确定度，我们建议保留但**不用于硬判决**，只用于「不确定 ⇒ 放行」。
3. 论文的 `r_C` 由目标像素规模决定，我们的 `r_K` 由**轨迹质量**（观测帧数/观测连续性/位移非退化）决定——同样体现「证据源不可靠就打折」的思想。

### 5.5 可比性 caveat（诚实声明，必须写进对外材料）

1. **任务不同**：论文是「前端已分割 + 序列分类」；我们是「端到端检测 + 跟踪 + 航迹级分类」。论文的面积来自**帧差二值掩码的连通域**，我们的代理面积来自**中心点热图的连通域**⇒ 两者不是同一个物理量，阈值不可直接搬运。
2. **零样本 vs 调参**：论文在 50/20/30 划分上标定（训练子集更新参数、验证子集调参早停、测试子集只算指标），但表 3 报告在 **236 段全量**上。我们若在 IR 数据上标定阈值后再报全量 236 段，就是**数据泄露**。因此必须**预注册阈值**（用业务域标定的阈值直接搬），并**额外**报告 in-domain 版本作为对照：
   - **(a) 零样本**：阈值来自业务域 → 与论文的「全量 236 段」对比（口径最接近论文，但阈值来源不同，需注明）。
   - **(b) in-domain 对齐**：在 IR 的「训练子集/验证子集」标定、在「测试子集」评估 → 与论文口径完全一致。

## 6. 79 段 `IR_BIRD` 的使用流程（困难负样本挖掘 + 阈值标定）

```
Step 0  解压 zip → Data/Video_IR/（只读操作，host 可做）
Step 1  ffprobe 批量统计 236 段的帧数/fps/分辨率/目标尺度分布
        → 校核 §5.3 的 600 帧假设；产出数据集画像表
Step 2  【需授权·服务器】用交付档模型（RC2 = trial_0080/weights/epoch3.pt）
        对 157 段 IR_DRONE + 79 段 IR_BIRD 做零样本推理
        → 落盘航迹记录 JSON（可被 point_annotator 导入的格式）
Step 3  【人工】用 manu/point_annotator/ 工具逐帧核验误检航迹
        → 三态标注 pos / neg / ign；输出「真鸟航迹」清单
Step 4  【服务器】对 Step 2/3 的每条航迹计算 §4.3 的 s_A / s_K 分布
        → 与业务域无人机航迹的同分布图对比 → 定阈值 τ_bird（预注册）
        → 注意：剔除/单列「近距离大型昆虫」样本（论文 §3.6.1 已预警）
Step 5  两条用法并行评估：
        (a) 作为航迹级规则的**阈值标定集**（不需要重新训练）
        (b) 作为**困难负样本**混入训练集做增量微调
            ⚠️ 微调属重活 → 必须服务器 + 用户当轮授权 + 受控 A/B
            ⚠️ 基线冻结：manu/data/build_full_median_dataset.py 严禁修改
```

**Step 3 的工具复用点**：`manu/point_annotator/point_annotator.py` 的 `PreAnnotationLoader`（`:450`）支持导入**跟踪记录 JSON**（`{"sequence", "per_frame": {"52": [{"pos":[x,y], "score":...}]}}`），输出三态标注 `{"video","resolution","frames":{"142":{"state":"pos|neg|ign","pts":[[x,y]], "pred_pts":..., "edited":bool}}}`。⇒ 航迹级统计（速度/位移/持续时长）需要我们自己写，标注工具本身**不提供 per-track 统计**。

## 7. 风险与前提

| # | 风险 | 机理 | 缓解 / 预期管理 |
|:--|:--|:--|:--|
| R1 | **远距滑翔飞鸟在航迹级也不可分** | 1~2 px PSF，滑翔阶段轨迹平滑匀速，与远距无人机同构（`hard_cases.md:23-27`） | 论文 §3.4.2 同样承认「飞鸟长时间滑行」导致面积特征不一致 ⇒ **`01_4485_1167-2666` 大概率仍然分不掉**。期望值按「能分掉扑翼型、能分不掉滑翔型」设定 |
| R2 | **代理量量化噪声淹没残差信号** | `area` 在 1~2 px 下只有 1–2 个灰阶 | 主用连续量 `sum`；`area` 只作成像质量指标（§3.1） |
| R3 | **时序噪声被误当成振翅** | 大气扰动 / FP16 量化 / 背景杂波产生与「鸟的周期性脉动」在频域上相似的宽带高频 | **不要只看高频能量幅度**。真正的振翅是「**面积脉动与运动位移同频同相**」；而噪声是二者的卷积 ⇒ 用**相干性/互相关**（面积序列与位移序列的频谱相位一致性）做二次确认，而不是单看幅度。这是相对论文的**增强点** |
| R4 | **误杀无人机（扑翼型）** | 论文 §3.6.2：机翼热源显著时扑翼无人机会被判成鸟 | 保守放行（§4.1-P3）：只有「面积脉动 + 运动高频」**双证据同时成立**且分数远超阈值才降权；判别只降权不删除 |
| R5 | **论文阈值不可直接搬运** | 面积来源不同（帧差掩码 vs 热图连通域）+ 尺度不同（320×256 vs 640×512） | τ 必须在本项目标定集上重新标定并**预注册**（§5.5） |
| R6 | **昆虫污染负样本集** | 论文 §3.6.1：近距离大型昆虫面积时序特征贴近小型鸟类 | Step 4 剔除/单列昆虫；昆虫在业务域也是合法干扰，**误判成鸟不致命**（正向虚警） |
| R7 | **域差异（FLIR Breach / 320×256 vs 业务域红外）** | 相机响应曲线、噪声特性、PSF 不同 ⇒ 频谱特征分布不同 | 阈值标定**必须在业务域数据 + IR_BIRD 两边分别做**，或只做**归一化后**的相对判据（如「残差波动占序列均值的比例」而非绝对值） |
| R8 | **种子噪声大于效应** | 本项目历史结论：单次运行的种子噪声可大于实验效应（`manu/memory/memory.md:1370`，§301） | 阈值标定必须**多段留一**交叉验证，报告分布而非单点 |
| R9 | **Python↔C++ 位级一致被破坏** | 板端内核与 Python 参考实现要求一一对应 | 新增 track 字段必须同步两处 + 过 `manu/pipeline/npu/track_fusion_align_test.cpp` |
