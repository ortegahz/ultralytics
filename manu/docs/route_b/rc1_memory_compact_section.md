## §32 🔒 RC1 封存：Epoch 3 = Release Candidate 1（路线 B 首轮试跑最佳产物）（2026-10-21）

- 🔒 **决策**：路线 B（1:3.09 全帧对等混训）5 epoch 里**最佳产物是 epoch3 而非 F1 最高的 epoch5**，
  已固化为 **Release Candidate 1 (RC1)**，并登记为**后续一切微调实验的对账基准**。
  详细证据与命令见 `memory.md` **§四十六**；机读登记 `manu/docs/route_b/RC1.json`。
- **三条量化依据**（全部可由 `runs/mixed_ft_route_b/gate/gate_history.jsonl` 复核）：
  ① **T1 源域虚警全场最低**：FP **941**（Ep1~Ep5 = 1232/988/**941**/1057/1023），**比基线 1014 还少 73**；
  Ep4/5 反弹破千，Ep5 F1 跌破 0.901（0.900501）= 源域散架征兆。
  ② **T2 目标域质量最高**：F1 **0.9989791016094163** 全周期峰值，FP **31** 为 Ep1~Ep5 最低，FN=3（Ep5 的 FN=2 差 1 帧，无实质差异）。
  ③ **T3 杂波抑制力最强**：FP **461** 全周期最低（净砍 129 个误检），且已完成 Ep5 全程涨幅的 **91.38%**
  （(0.8716843671438099−0.8373308251032032)/(0.8749235474006115−0.8373308251032032)=0.9138）。
- **锁定 Ep3 而非 Ep5 的核心理由（边际收益递减 + 轻度过拟合）**：Ep3→Ep5 又跑满 2 个完整 epoch（约 40 min 算力），
  T3 F1 只 +**0.0032**（0.871684→0.874924）而 T3 FP 由 461 **回升到 502**；
  T1 F1 再损 **−0.001417**（≈−0.14pp）、T1 FP 由 941 回升到 1,023。train loss 继续下探（0.4171→0.3828）
  但 val 端虚警全面反弹 ⇒ Ep4~5 属边际收益递减/轻度过拟合区间。
  ⇒ **锁定 Ep3 = 强判别 + 低虚警 + 轻泛化的最佳交点。**
- 🔴 **必读限定（不夸大）**：
  ① **原始 T1 红线（F1 ≥ 0.905736 去 P0 冻结基线）在 Ep1~Ep5 全部未通过**，RC1 自身 T1 F1=0.901917808219178
  同样判负（`gate/epoch3/gate_report.json`：`veto_failures=["track1_uav"]`, verdict=FAIL, rc=1）
  ⇒ **RC1 的依据是"帕累托最优 + 虚警最低"，不是"通过原始三轨红线"**。
  ② **T1 峰值门限漂移**：基线/Ep1 峰值 th=0.25，Ep2~Ep5 峰值 th=0.30；跨 epoch 对比是"各模型自身最优门限下"的比较，
  须连同 `delta.negative_bands=7/15`、`delta.mean_f1=+0.001309` 一并看。
  ③ **三轨口径天生不对称，不可横向比较**（§四十三 §2）。
  ④ **T2「FP 增量 ≤ 10」的唯一攻击点仍是 000703**（基线 FP 4 → Ep5 FP 29，Δ+25，占黄金池总误报 88%），下一轮定点攻它。
- **RC1 指纹与路径**：服务器 `runs/mixed_ft_route_b/RC1/epoch3.pt`（21,301,091 bytes，**0444 只读封存**），
