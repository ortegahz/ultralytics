## 零、算法演进全景脉络与心路历程 (Evolution Roadmap)

基于实际工程推进路线，将全周期算法演进划分为四个核心阶段（对应 `manu/plan.md` 14 个技术节点与后续深化），完整记录“提出设想 → 实验验证 → 归纳定性/扬弃”的闭环过程：

```
阶段一：数据与单帧检测器选型 (Nodes 1-4, 6, 7, 14)
  数据治理 (公司数据多样性不足 -> 引入 anti-uav 红外学术数据集)
  -> YOLO26 框架选型与 Baseline (标准 Anchor/Bbox)
  -> P2 极小特征层引入 (Stride=4, 160x160 特征图)
  -> Optuna 超参搜索 (AP50 -> Recall 导向，产出 trial_0028)
  -> 尺度探索 (imgsz=1280 显式训练 / 960 推理探针)

阶段二：时序信息编码与端到端多帧尝试 (Nodes 5, 8, 9, 13)
  帧差输入 (FD 3 通道 [I_t, |I_t - I_{t-1}|, |I_t - I_{t-2}|])
  -> 各种长时序列特征实验 (大跨度差分、带符号差分、速度通道门控)
  -> 增加显式监督 (多帧位置与运动矢量联合预测，缺乏密集标签引导)
  -> 3-Frame 原始图像堆叠 [I_t, I_{t-4}, I_{t-12}] (隐式 AND 约束证伪)
  -> 局部相关层 Hybrid Corr [I_t, |I_t-I_{t-2}|, I_{t-8}] (R=2 绞杀中高速目标证伪)

阶段三：表示范式重构与主干探索 (Nodes 10, 12)
  Heatmap-based 范式跃迁 (CenterNet 风格，无 Anchor/无 NMS，解决极小框塌缩)
  -> P2 (Stride=4) -> P1 (Stride=2, 320x320) 高分辨率分支 (锁定 trial_0031 早期基线)
  -> 专用 IRSTD-UNet 主干探索 (密集 S1/S2 跳连 + ACM 上下文调制 + PixelShuffle + Soft-IoU Loss)

阶段四：确定性物理对齐、时域中值背景建模与超参大突破 (Nodes 11, 最新重大突破)
  双门限运动学航迹滤波 (CFAR 局部方差自适应 + 卡尔曼航迹滤波，攻克 DJI_0175_2)
  -> 空间先验自适应门限 (Scheme 2 + Scheme 5 融合，大盘 F1 达 0.8895)
  -> GMC 全局运动补偿 (消除抖动结构性假警，全盘 F1 达 0.8902)
  -> 21 帧时域中值背景残差 [I_t, |I_t - W(I_{t-2})|, (I_t - B_t)^+] (物理降噪 sqrt(N) 倍，突破 0.8975)
  -> 4-GPU 分布式 Optuna 搜索 (锁定 Trial 22: focal_beta=2.4 负样本软化，全盘 F1 首次突破 0.9058 SOTA)
  -> 双向时空平滑、碎片航迹缝合与高确信插补 (方案一：大盘 F1 历史性突破 0.9154 SOTA)
  -> PixelShuffle 亚像素解码微调尝试 (未初始化卷积冲垮预训练先验，F1 衰退至 0.8658 证伪)
  -> 空时双残差 Dual-Domain Top-Hat 零训练探针 (直流能量基底坍塌致热图峰值萎缩，F1 降至 0.5932 证伪)
```

## 零点一、早期探索阶段实验归档 (Early Experiments Archive)

对应 `manu/plan.md` 前期技术验证。部分早期实验未保留细粒度逐序列大盘，现将其核心技术事实与工程定论建档归纳：

### 1. 任务背景与数据集选型 (Nodes 1-3)
- **业务痛点**：公司自采红外无人机数据存在场景单一、机位相对固定、低空背景单调等问题，数据多样性严重不足，直接作为检测器泛化基础极易过拟合。
- **学术数据集引入**：全面调研 IRSTD/Anti-UAV 领域前沿（如 Vistarget、Anti-UAV、SPIRE-IRSTD 等），引入学术界标杆红外弱小无人机数据集（如 24 个验证序列大盘，总计 31,613 帧、25,111 个真实标注框）。该数据集覆盖机载抖动、地空过渡、极小微弱脉冲（1~3px）、超低信噪比（SCR < 1.0）等大量极端边缘场景，作为算法研发基准。

### 2. YOLO26 标准检测器与 P2 Head 引入 (Nodes 4, 6)
- **初始基线（Node 4）**：以标准 `YOLO26n` 作为目标检测 baseline（输入 640x640，主干下采样到 P3/P4/P5，即 Stride 8/16/32）。实测发现对 1~3 像素点目标，经过 P3（80x80）下采样后高频冲激响应严重稀释，大量目标在特征图上连 1 个网格都无法占据，单帧 Bbox 回归召回率极低。
- **P2 Head 极小目标分支（Node 6）**：
  - 引入 P2 特征分支（Stride=4，160x160 尺度），直接将浅层高分辨率纹理送入检测头；
  - 显著提升了 5px 左右小目标的捕获能力，成为后续所有网络架构的标准颈部标配（`yolo26np2.pt`）。

### 3. 多卡并行超参搜索演进 (Node 7)
- **阶段 1：AP50 导向搜索（`optuna_parallel_uav_ap50.py`）**：
  - 使用 4 张 GPU 开展 Optuna 分布式搜索，以标准 COCO `metrics/mAP50(B)` 为优化目标；
  - 现象：模型倾向于压低假警来换取高 Precision 和 AP50，但安防/光电跟踪最核心的暗弱目标召回（Recall）受到抑制。
- **阶段 2：Recall 导向搜索（`optuna_parallel_uav_recall.py`）**：
  - 切换适应度函数为 `metrics/recall(B)`，全面放宽学习率与小尺度几何尺度增强；
  - 产出 Bbox 范式下的最优模型 **`trial_0028`**（Recall=75.61%，Precision=77.03%，F1=0.7631），成为此后所有 Heatmap 范式对比的 Bbox 绝对基准。

### 4. 尺度探索实验：1280 训练与 960 推理 (Node 14)
- **1280 高分辨率显式训练（`train_uav_from_optuna_1280.py`）**：
  - 基于 Optuna 最佳超参，尝试输入尺度 `imgsz=1280` 进行正式训练；
  - 结论：计算量与显存消耗急剧膨胀 4 倍，小目标等效面积放大，但由于训练集长尾目标本身模糊，大尺寸训练极易学习到大块地表斑块噪声，综合收益性价比极低。
- **960 跨尺度免训直接推理（`val_heatmap_960.py`，详见第九章第 2 节）**：
  - 640 权重直接在 960 下推理，高斯核尺度失配，同阈值下 FP 从 1,364 飙升至 6,352（暴增 4.6 倍），彻底证伪免训练放大尺度路线。

### 5. 运动矢量与多帧监督联合预测尝试 (Node 9)
- **设计初衷**：在单帧检测头中增设多任务辅助分支，不仅预测当前帧目标热点/框，同时强制网络显式回归相邻帧目标位置偏移量（位移矢量 $\Delta x, \Delta y$），期望通过多时序几何强监督约束特征提取器。
- **实测结论**：弱小点目标在红外场景缺乏密集光流/密集纹理特征，背景抖动与真实位移耦合严重；在缺乏密集位移真实标签、仅依靠稀疏边界框监督时，辅助运动头梯度回传震荡，未能带来稳定正向增益，后续将运动学建模重心转移至后端滤波。

## 一、当前检测器技术基准与最优冠军模型 (Current SOTA Baseline)

### 1. 最终锁定的工程冠军模型 (NEW ABSOLUTE SOTA)
- **模型标识**：**`Trial 22` (位于 `runs/optuna_median_search/trial_0022/weights/best.pt`)**
- **网络架构**：`YOLO26HeatmapDetector`
  - YOLO26 骨干 + P2 颈部 + Stride=2 P1 高分辨率输出分支（输入 640x640，热图 320x320）
  - CenterNet 风格热图关键点概率回归 + 亚像素坐标偏移量微调
- **输入特征形态**：**3 通道时域中值背景残差输入 `[I_t, |I_t - W(I_{t-2})|, (I_t - B_t)^+]`**
  - 通道 0：原始红外灰度帧 $I_t$；
  - 通道 1：GMC 2-lag 光流仿射对齐差分 $|I_t - \mathcal{W}(I_{t-2})|$；
  - 通道 2：21 帧滑动窗口 GMC 光流仿射对齐时域中值残差 $(I_t - B_t)^+$（正向残差，压低焦平面本底噪声 $\sqrt{N}$ 倍）。
- **优化与损失核心机制**：
  - **Focal Loss 负样本软化（`focal_beta = 2.4`）**：彻底解除原版 $\beta=4.0$ 在全图海量背景像素上对弱脉冲目标的过度压制；
  - **精细化微调**：`lr0 = 1.44e-4`, `weight_decay = 3.54e-5`, `scale = 0.05`, `mosaic = 0.0`；
  - **单轮达峰**：从 `exp_6ep_median` 热启动微调 1 个 Epoch 达到最优泛化极值。
- **判决规范**：统一以 **Distance <= 8.0px**（GJB/行业安防光电标准）及 **Distance <= 4.0px** 双重验证。

## 二、最新实验深度复盘：3-Frame 原始时空微调方案

为了解决极暗弱慢速目标的“相邻帧自抵消”问题，设计并实施了 3-Frame 原始图像方案：
- **方案实现**：从原始视频抽取 [I_t, I_{t-4}, I_{t-12}] 合成 3 通道图片生成 uav_temporal_3frame 数据集（前 12 帧采用 Clamp 回退机制），利用 Optuna 进行了 4 卡并行微调（代表模型：trial_0028_）。
- **实测表现与 PR 曲线分析**：
  1. **高门限工况（th=0.35）**：Precision 飙升至 **96.44%**，虚警数降至 763 个（降幅 44%）。
  2. **长尾打捞工况（th < 0.30，PR 曲线形态）**：**发生灾难性“垂直断崖下跌”**。在 Recall 超过 83% 后，曲线直接垂直砸穿至 65% 以下，抗长尾弱目标下潜打捞能力远差于 trial_0031。
- **物理成因定性**：
  1. 3 帧原图堆叠强加了“隐式逻辑与（AND）”约束，要求目标在 3 个时相全部清晰连续，对真实红外弱目标的“闪烁/瞬态暗化”毫无容错；
  2. 低阈值下，三帧完整背景的微小几何错位（云层微移、地表抖动）发生雪崩式伪目标爆发。
- **工程决策**：**正式放弃 3-Frame 原始图像堆叠微调路线，回退并永久锁定 trial_0031 为最终交付基线。**

## 五、重大实验复盘：局部特征相关层方案 (exp_corr_v1) 的实测事实与物理死穴

为了解决超暗弱慢速难例（如 `wg2022_ir_020_split_03` 目标 2px、$\Delta I < 1.5$ 灰度级在短差分下的“自抵消”问题），我们设计并实施了**方案 A 混合局部特征相关网络（Hybrid Correlation Temporal Stem）**：
- **方案实现**：
  - 构造专属混合输入数据集 `uav_hybrid_corr`：`[I_t, |I_t - I_{t-2}|, I_{t-8}]`（保留短差分，引入 8 帧跨度原图）；
  - 在 Stride=2（320x320）浅层特征尺度搭建 `LocalCorrelationBlock`，提取 $I_t$ 与 $I_{t-8}$ 的归一化局部点积相关体（搜索半径 $R=2$，覆盖 25 个速度假设通道）；
  - 与空间外观、短时差分特征融合后送入骨干，基于 `trial_0031` 权重进行了 20 轮全量微调。

### 1. 实测大盘对比结果（Unified Distance <= 8.0px, GT = 25,111）
- **Recall（召回率）**：从基准的 **84.51% 大幅暴跌至 78.77%**（净丢失 **1,442 个真值目标**！）；
- **Precision（精确率）**：94.99%（虚警控制优异，证明相关层确实具备较强的白噪声与静态背景压制力）；
- **F1-Score**：从基准的 **0.8898 下滑至 0.8612**；
- **PR 曲线全局形态**：
  - 再次复现了此前 3-Frame 方案的**断崖式崩塌形态**；

### 2. 深度物理成因与机理定性（为什么全面落后？）
1. **隐式“双重时相强连续假设（AND 逻辑）”的负面代价远超收益**：
   - 特征局部相关依靠 $F(I_t)$ 与 $F(I_{t-8})$ 的点积。这强行要求目标在相隔 8 帧（约 0.32 秒）的两个时刻**必须同时清晰存在且辐射特征稳定**；
   - 真实红外弱小目标极易出现姿态翻滚暗化、云层微遮挡、探测器瞬态闪烁。只要目标在 $t-8$ 稍有暗化，点积能量直接归零；
   - 为了挽救占比不到 3% 的超慢速极端暗弱目标，强行引入 8 帧强相关假设，**代价是直接牺牲了大盘中占比更高的大量瞬态闪烁与边缘过渡目标**。
2. **搜索半径 $R=2$ 成为“中高速/机动目标自杀绞索”**：
   - 特征图 $R=2$ 仅对应原图 $\pm 4$ 像素的搜索窗口；
   - 8 帧跨度下，大盘中大量近距机动或中速飞行的无人机位移往往达到 10~25 像素，**早已大幅超出局部相关窗的视野范围**；
   - 超出窗口后，目标在 $t-8$ 的历史像素不仅无法形成相干峰，反而在空间上被网络感知为非对齐的伪异常噪点，引发特征抑制与漏检。
3. **缺乏密集运动真值显式监督导致特征退化**：
   - 局部相关层（RAFT/FlowNet）在光流领域有效的前提是有稠密光流标签直接约束；
   - 本方案仅靠最终的高斯热图端到端回传梯度，网络缺乏显式引导去区分 25 个速度假设通道，极易退化或对复杂背景产生次优响应。

### 3. 终极工程决策
**正式终结在模型前端主干中引入多帧堆叠、长跨度差分或局部相关层的端到端探索路线。永久锁定短时差分 `trial_0031`（[I_t, |I_t-I_{t-1}|, |I_t-I_{t-2}|]）为交付基准，任何针对极暗弱长尾样本的突破，必须转移至系统级后端（空域分区门限 + TBD 航迹滤波），严禁再通过重构检测器主干“因噎废食”。**

## 八、全盘大范围突破：空间先验自适应门限与双门限运动学滤波融合 (Scheme 2 + Scheme 5 Fusion)

为了系统性提升大盘综合指标（Recall、F1-Score 与虚警控制），我们在保持 `trial_0031` 模型权重完全不动的前提下，融合设计并落地了**方案二（空间先验分区门限）**与**方案五（双门限运动学航迹滤波）**，产出全盘评测系统 `manu/eval_spatial_kinematic_fusion.py`。

### 1. 核心算法设计与纠偏演进机制
1. **双门限分级打捞与防虚警闭环（Two-Stage Gating）**：
   - **高确信度检测（Score >= 0.20）**：作为主航迹发起与更新源；
   - **弱脉冲打捞池（0.06 <= Score < 0.20）**：**严禁自发生成新航迹**，只允许被现有存活航迹在运动学门限（`match_dist=12.0px`）内进行打捞，从数学上杜绝传感器随机白噪声串接为假警航迹。
2. **零延迟直通机制（Zero-Latency Instant Pass, `instant_conf=0.30`）**：
   - 彻底解决传统 `min_hits=3` 导致的“冷启动固有吞噬”（每条航迹前 1~2 帧被吞）；
   - 首帧单点置信度 >= 0.30 的清晰目标立即直通报案，保全高质量序列的无损召回。
3. **静态微动地物与聚集度抑制（Stationary Clutter & Density Filter）**：
   - 航迹存活 >= 5 帧但累计位移 < 2.5px 的目标定性为地表边缘微抖伪目标，整条截断销毁；
   - 弱脉冲打捞候选若在 25px 范围内聚集超过 2 个邻居，判定为成片地物纹理直接剔除。

## 十一、全局运动补偿 (GMC) 与配准数据集实测突破与深度复盘 (2026-09-09 最新攻坚)

依据 `claude-opus-5.md` 的 P1 建议，我们启动了针对抖动杂波难例（以 `DJI_0051_2` 为代表）的 **GMC 全局运动补偿 + 时域差分** 探索。

### 1. 核心物理机理与方法论澄清
- **严禁使用差分图估计 GMC 变换矩阵**：差分图只剩下高频残差白边，静止背景灰度几乎全为 0，缺乏足够纹理梯度，ECC/光流必然漂移；
- **正确时序链路（P1 标准流程）**：
  1. 取原始灰度原图：$I_t, I_{t-1}, I_{t-2}$；
  2. 在原图上通过 SparseOptFlow（稀疏 LK 光流 + RANSAC）估计相机刚体仿射变换矩阵 $H_{t-1 \to t}, H_{t-2 \to t}$；
  3. 用 $H$ 去 warp 历史原始帧：$\mathcal{W}(I_{t-1}), \mathcal{W}(I_{t-2})$；
  4. 历史原图对齐到当前帧坐标系后，再与当前原图逐像素相减：$\text{diff}_1 = |I_t - \mathcal{W}(I_{t-1})|, \text{diff}_2 = |I_t - \mathcal{W}(I_{t-2})|$；
  5. 合成 3 通道输入 $[I_t, \text{diff}_1, \text{diff}_2]$ 送入模型。
- **物理收益**：地表树林、建筑物等由于相机晃动产生的位移被精确对齐抵消，结构性白边假警从数学上消除；独立空气动力学运动的无人机残差被完整保留。

## 十二、专用 IRSTD-UNet 主干架构探索与定性 (Node 12 Archive)

为了对标学术界主流红外弱小目标专用分割网络（ACMNet、DNA-Net、UIUNet、RDIAN），在探索后期独立搭建了 `IRSTDNet` 专用网络实验体系（`manu/irstd_unet_model.py`、`manu/irstd_loss.py`、`manu/train_irstd_unet.py`）：

### 1. 架构与损失函数设计
1. **密集浅层细节跳连 (Dense Skip Connections)**：
   - 保留 Stride 1（640x640）和 Stride 2（320x320）高分辨率浅层冲激特征，避免通用检测骨干（YOLO/ResNet）在下采样中过度稀释 1~3 像素点目标的高频脉冲；
2. **非对称上下文调制与通道门控 (ACM / Channel Gate)**：
   - 残差块内嵌轻量级通道注意力（SE 模块），区分等方性高斯能量分布与各向异性的地面长条形杂波；
3. **亚像素卷积重建头 (PixelShuffle Sub-pixel Decoder)**：
   - 弃用传统的双线性插值平滑上采样，采用 PixelShuffle 直接解码出锐利的峰值概率图（`prob_map`）与亚像素级位移图（`offset`）；
4. **多任务混合损失函数**：
   - **Soft-IoU Loss**：缓解前景极度稀疏（正负像素比 1 : 100,000+）带来的损失主导失衡；
   - **加权 BCEWithLogitsLoss**：抑制全图平坦区域假警；
   - **RegL1Loss**：回归目标精确中心偏移量。

### 2. 核心定性与技术汇报定位
- **与当前冠军基线的关系**：
  - IRSTD-UNet 属于**全新网络拓扑从零训练**路线。实测表明（Epoch 1: FP=232,466, Epoch 2: FP=148,037），从零训练新主干在缺乏大样本预训练的情况下，极易在地表复杂纹理上被海量假警冲垮，收敛极慢；
  - **核心技术沉淀**：其实用价值主要体现在其针对弱小目标的**损失函数设计（Soft-IoU + 加权 BCE）**，主干网络仍需坚定锁死在成熟收敛的 YOLO26HeatmapDetector 上。

## 十三、时域中值残差与负样本软化重大突破：F1 突破 0.9058 封王记录 (Trial 22 Absolute SOTA)

为了解决红外弱小目标极低信噪比慢速自抵消、以及 Focal Loss 负样本惩罚过重导致暗弱目标在多轮微调中严重衰退的问题，开展了**物理层确定性中值背景残差建模 + 4-GPU 分布式 Optuna 搜索（负样本惩罚软化 $\beta=2.4$）**的系统性攻坚。

### 1. 核心理论突破与参数化设计
1. **物理层中值背景残差注入**：
   - 构造 3 通道输入：`[I_t, |I_t - W(I_{t-2})|, (I_t - B_t)^+]`；
   - 经 GMC 仿射对齐的 21 帧滑动时域中值残差，将传感器焦平面随机白噪声压低 $\sqrt{N} \approx 4.5$ 倍，慢速暗弱无人机的局部对比度 $\Delta I$ 从 2~3 灰度级直接提升至 **15~33 灰度级**，彻底打破了物理自抵消盲区；
   - 保持 100% 官方镜像划分（Train 43,008 / Val 31,613，总 GT=25,111），实现绝对零坐标漂移。
2. **负样本梯度惩罚解绑 (`focal_beta = 2.4`)**：
   - 原版 CenterNet $\beta=4.0$ 在全图海量背景上累积过强负梯度，导致网络“过分胆小”，将 0.08~0.15 的真实暗弱脉冲无差别拍死；
   - Optuna 128 个 Trial 搜索出的黄金参数集中在 $\beta \in [2.0, 2.4]$；

## 十五、多时相联合热图监督 (Multi-Timeframe Heatmap) 实测复盘与证伪归档

为了探索能否通过在训练期引入时空管道多时相高斯监督（缓解单点高斯正样本极其稀疏、正负比 1:100,000+ 痛点），我们设计并实施了**方案 A 多时刻联合热图监督消融实验**（`manu/build_mth_dataset.py`、`manu/multi_timeframe_model.py`、`manu/multi_timeframe_loss.py`、`manu/train_multi_timeframe_heatmap.py`）：

### 1. 方案设计与严格单变量控制 (Strict Single-Variable Ablation)
1. **数据集严格对齐构建 (`uav_gmc_mth`)**：
   - 图像部分：100% 软链接复用成熟的 `uav_gmc_median` 图像，零磁盘冗余；
   - 标签部分：从 `anti-uav` 原始序列 `IR_label.json` 抽取物理真实的 $t-1$ 与 $t+1$ 帧目标中心，并通过 SparseOptFlow 仿射变换矩阵 $H_{t-1 \to t}$ 和 $H_{t+1 \to t}$ 精准投影到当前帧坐标系，彻底消除相机晃动带来的坐标伪偏移；
2. **纯粹 Focal 损失监督（剔除 Soft-IoU 变量）**：
   - Head 扩展为 3 通道输出：`[H_t, H_{t-1}^{\text{aligned}}, H_{t+1}^{\text{aligned}}]`；
   - 监督损失：$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{focal}}(H_t) + 0.35 \cdot [\mathcal{L}_{\text{focal}}(H_{t-1}) + \mathcal{L}_{\text{focal}}(H_{t+1})] + 0.45 \cdot \mathcal{L}_{\text{offset}}$；
   - 严格继承 `Trial 22` 的最优黄金超参数：`beta=2.40, lr0=0.000144, lrf=0.050, weight_decay=3.5e-5, off_w=0.45, radius=1, scale=0.05, translate=0.04, mosaic=0.0`。
3. **推理与评估规范**：
   - 严格评估 Channel 0（当前时刻 $H_t$），采用 Distance <= 8.0px 标准公正测试。

### 3. 深度物理机理诊断（为什么多时刻监督会崩塌？）
1. **时序辅助分支损失膨胀，主导并剧烈冲击浅层共享梯度**：
   - 实测训练 Loss 显示：中心帧 `HM Loss = 1.0717`，而时序分支 `Temp Loss = 3.8869`，总 Loss 飙升至 `2.5256`（对比原 Trial 22 正常训练 Loss 仅 `0.3680`）；
   - 即使乘以 `temporal_weight = 0.35`，时序误差在浅层反向传播梯度中依然占据了超过 **60% 的主导份额**；
   - 单帧前向特征要同时精准回归过去和未来的离散点属于病态难题，巨大的时序反向梯度剧烈冲击了浅层共享特征层，把原本高度聚焦收敛的当前帧 $H_t$ 能量打散、边缘模糊化，导致最佳门限被动拉高到 0.35，大量临界弱目标直接丢失。
2. **多任务能量争夺与负迁移（Negative Transfer）**：
   - 红外弱小目标局部信噪比极低（很多只有 2~3 个灰度级），浅层特征图容量极其宝贵；
   - 强迫网络分出通道和容量去编码前后时序高斯分布，直接削弱了对当前时刻微弱冲激能量的汇聚能力，导致暗弱目标峰值幅度大幅萎缩。

### 4. 终极工程决策
**正式证伪“在检测头中引入多时刻概率 Heatmap 联合监督”的技术路线。**

### 2. 深度讨论与机理诊断：初步尝试未见提升的成因分析

单次手动设定参数的微调未能超越 SOTA，经深入研判存在以下三个核心系统性诱因：

1. **损失数值量级倒挂，Soft-IoU 反向梯度喧宾夺主**：
   - 训练日志显示：`HM Loss (Focal) = 0.2641`，而 `IoU Loss = 0.7904`；
   - 手动设置的 `soft_iou_weight = 1.0` 使得 IoU 损失在数值上达到了 Focal Loss 的 **3 倍**，在浅层共享梯度的反向传播中占据了 75% 的主导权，喧宾夺主；
   - CenterNet 依赖尖锐的高斯冲激响应（1~2 像素峰值），而连续形式的 Soft-IoU（$\frac{P \cdot G}{P + G - P \cdot G}$）倾向于惩罚整个高斯裙边的不重合，强迫网络把尖锐脉冲“摊平铺宽”来追求更大的交并比，削弱了中心峰值能量，导致 252 个弱目标热图峰值跌落至 0.25 门限以下。
2. **总 Batch Size 放大 4 倍导致优化步数剧烈压缩**：
   - 本次采用了 4 卡 `DataParallel`，总有效 Batch Size 达 **128**；
   - 单 Epoch 步数从单卡的 1344 步压缩至仅 **336 步**，6 个 Epoch 全程仅迭代了 **2016 步**；
   - 初始学习率未根据线性缩放准则放大，权重在过少的迭代步数内难以在新的多目标损失曲面上平滑寻优收敛。
3. **超参数未精细寻优（潜在潜能仍未释放）**：

## 十七、双向时空平滑、碎片航迹缝合与高确信插补重大突破：F1 突破 0.9154 历史新极值 (Scheme 1 SOTA)

为了突破传统在线因果单向滤波在目标瞬态暗化、云层微遮挡时频繁断轨导致的真值吞噬与碎片化，于 2026-09-10 实施了**方案一：双向时空平滑关联 + 碎片航迹缝合 + 高确信航迹受控插补系统**（`manu/eval_bidirectional_track_fusion.py` 与 `manu/tune_bidirectional_fusion.py`）。

### 1. 核心理论机制与算法架构创新

1. **时序碎片航迹缝合 (Kinematic Tracklet Stitching)**：
   - **痛点**：红外弱小目标在姿态机动或气流扰动下极易出现 1~4 帧短暂暗化，导致在线跟踪器判死后另起新轨，一条完整飞行轨迹被严重割裂成多个离散碎片；
   - **机制**：在完整序列时空有向图中，提取各航迹碎片终点的运动学状态（末端速度矢量 $\vec{v}$ 与位置），在时间断裂带（$1 \le \Delta t \le \text{stitch\_gap}=4$ 帧）内进行动力学外推。若空间距离与速度对齐度满足空气动力学物理容差（$\text{dist} \le \max(25.0, 10.0 \times \Delta t)$），将碎片平滑连接合并为单条长航迹。
2. **高确信航迹受控插补 (Confirmed Track Infill / RTS-like Interpolation)**：
   - **安全防线**：严格设定成熟度门槛，**仅对存活累计命中 $\ge 5$ 帧的高置信度真实航迹（`min_hits_infill=5`）**开放插补权限；未确信的偶发杂波或短寿命伪航迹严禁插补，从机理上封死虚警泄露；
   - **动力学双向插值**：对已确信航迹内部出现的短暂失锁间隙（$\le 3$ 帧），依据前后观测点进行平滑动力学插补，直接变现为真实 TP。
3. **冷启动前缀无损回填 (Prefix Recovery)**：
   - 彻底消除了传统 $M/N$ 关联滤波必须等待 2~3 帧确认才能输出的“冷启动固有吞噬”，航迹确认后自动追溯回填前 1、2 帧的初始观测，实现全生命周期零漏检。

### 3. 深度物理成因与机理定性（为什么零训练发生全面塌陷？）
1. **直流能量基底严重坍塌（Feature DC-Shift）**：
   - 原始灰度帧 $I_t$ 的背景平均灰度通常在 100~140 灰度级（具备极高的直流偏置）；

2. **极弱目标的亚阈值过冲被形态学开运算削平**：
   - 对信噪比极低的 1~2px 点目标（$\Delta I < 2$），形态学开运算将微弱高斯能量误判为平缓起伏垫底，导致目标残差被直接吃掉，使四大难例在 0.25 下完全全军覆没。
